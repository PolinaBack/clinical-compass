# Семейное дерево с листиками

Пациент открывает **Профиль → Обо мне → Семейное дерево**. Возвращены крона, мягкий фон, ствол, изогнутые ветви и форма листьев из предыдущей версии `43bbc4a`. По новому пожеланию листья зелёные. Врач по-прежнему видит медицинскую родословную из тех же сведений.

- Нажмите **листик «+»**, **свободный листик** или **Добавить ещё родственника**.
- Выберите родство. Имя можно не указывать; начните с любого близкого. Сестра, брат, бабушка, дядя или своя категория добавляются без заполнения родителей.
- Если не знаете, по какой линии бабушка/дедушка, выберите вариант **линия не уточнена**.
- Для своего названия выберите **Другая / Своя категория**, например «Двоюродная сестра», «Приёмная мама» или «Крёстный».
- Возраст, пол, заметка, сведения об умершем и связь с родителем добровольны. Приложение не требует и не создаёт остальных родственников.
- Нажмите **Добавить участника**. После сохранения человек появляется на зелёном листе. Перезагрузка не удаляет запись.
- Нажмите заполненный лист: можно изменить имя, короткую заметку и дополнительные сведения. Для подробностей нажмите **Подробная семейная история и сведения о здоровье** — прежние вкладки, факты, источники и отметки для обсуждения сохранены.

На телефоне дерево можно двигать пальцем в стороны и вверх/вниз внутри его поля. «+» при открытии находится в центре, кнопка добавления также есть под деревом. Форма помещается на экране. Escape или крестик закрывает окно, фокус возвращается на листик. Без JavaScript открывается отдельная короткая форма одного человека.

Пустые листья с подписями «Мама», «Папа» и другими ролями — места для добавления. Пока вы не сохранили человека, соответствующей записи в базе нет. Повторно создать того же отца или мать нельзя; старые записи и собственные категории сохраняются.

## Посмотреть обновление в PyCharm

Остановите приложение через **Ctrl+C**. В Terminal, из папки проекта:

```powershell
.\.venv\Scripts\python.exe -m scripts.backup data\backups\before-family-leaves.db
git status
git switch feat/local-mvp
git pull --ff-only origin feat/local-mvp
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

Для копии выберите другое имя, если такой файл уже существует. Если Git сообщает о локальных правках, сохраните их отдельным коммитом и повторите обновление; принудительный сброс не нужен. Базу не удаляйте и не заполняйте заново. Новых пакетов и новой миграции это обновление не требует.

Откройте http://127.0.0.1:8000. Достаточно обычной перезагрузки страницы: версии стилей и скриптов меняются автоматически. Для проверки мобильного вида: **F12 → значок телефона**, ширина 390 или 320.

Проверки в Terminal PyCharm:

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_family_leaves.py tests/test_family_editing.py tests/test_assets.py -q
.\.venv\Scripts\python.exe -m pytest -q
```
