Для C-SSRS достаточно передать экспорт выбранной страницы/официального PDF вместе с точной версией и назначением формы. Если это врачебное интервью, оно не публикуется как самостоятельная пациентская анкета. В текущем прототипе специалист может записать результат беседы по внешней форме с источником, версией и отдельной понятной пациенту сводкой; такая запись не создаёт фиктивных ответов пациента.
