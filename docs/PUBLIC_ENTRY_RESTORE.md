# Прежнее оформление главной и входов

По уточнению пользователя от 26.10.2026 восстановлен внешний вид публичной главной и форм входа пациента/специалиста. Ориентир — базовое оформление до добавления общих стилей кабинетов (`1e68aa5^`). Шаблоны содержания главной и форм входа уже совпадали с этой версией; проблема была в применении общего оформления кабинетов к этим страницам.

На `/`, `/login/patient`, `/login/specialist` и ответе с неверным паролем используются прежние базовые цвета, шрифт, отступы, шапка со знаком-звёздочкой и ссылки публичной навигации. Стили кабинетов туда не подключаются. Открытие главной уже вошедшим врачом тоже не переносит на неё оформление кабинета.

Внутри кабинетов остаются текущие навигация, библиотека и добавление лекарств. Аккаунты, пароли, права, переходы после входа, защита CSRF и независимые одновременные сеансы не сбрасываются. Для неверного пароля сохранён ответ 401, но форма теперь получает полный общий контекст и остаётся пригодной для повторного входа.

В терминале PyCharm, в ветке `feat/local-mvp`:

```powershell
git pull --ff-only origin feat/local-mvp
```

Перезапустите сервер и обновите страницу сочетанием Ctrl+F5. Очищать БД не нужно.

Ручная проверка:

1. Выйдите из кабинета; откройте `/` и обе кнопки выбора роли. Проверьте прежнее оформление и поля логина/пароля.
2. Введите неверный пароль: на той же оформленной форме появится ошибка. Затем войдите с прежними правильными данными.
3. Убедитесь, что в кабинете врача доступны обновлённая библиотека и добавление лекарства, а пациент попадает в свою карту.
4. Выйдите: должна открыться главная с прежним оформлением.
