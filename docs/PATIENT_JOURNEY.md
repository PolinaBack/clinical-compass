# Сезонная дорожка пациента

26.10.2026 · U-PATIENT-JOURNEY-26.

Над верхним меню пациента появилась дорожка в стиле присланного примера: лес, мостик и человечек с компасом. Она видна в кабинете над дневником, профилем, анкетами, статистикой, выписками и настройками. Главная и страницы входа сохраняют прежний вид, у врача дорожки нет.

Полный путь — **90 заполненных дней**, как выбрал пользователь. Каждый отдельный сохранённый день дневника продвигает человечка на одинаковую долю пути. Несколько записей за одну дату дают один шаг; открытие анкеты, изменение полей без сохранения, оценки настроения и отметки о приёме лекарств положение не меняют. Пропуски не отнимают пройденное расстояние. Заполненные задним числом отдельные даты учитываются. Будущие и некорректные даты в прежних данных не засчитываются.

Счётчик строится по существующим записям пациента, поэтому уже заполненные даты тоже учитываются. На 90-м дне человечек доходит до конца, появляется «путь пройден». После этого дневник можно продолжать заполнять; достигнутый путь остаётся полным.

Оформление автоматически соответствует текущему сезону по Москве:

| Месяцы | Оформление |
|---|---|
| Март — май | Цветущие деревья и сиреневая куртка |
| Июнь — август | Зелёный лес и лёгкая зелёная одежда |
| Сентябрь — ноябрь | Золотая листва и тёплая оранжевая одежда |
| Декабрь — февраль | Заснеженный лес, синяя куртка и шапка |

Смена сезона сохраняет накопленные дни. При открытии страницы положение рассчитано сервером. Открытая вкладка обновляет состояние примерно раз в минуту и при возврате к ней, поэтому новые записи другого окна и смена сезона появятся без ручной перезагрузки. При потере связи остаётся последний подтверждённый счётчик. Дата формы дневника и проверка будущей даты также используют московский день.

Без JavaScript сервер всё равно показывает правильный прогресс; плавное перемещение и фоновое обновление требуют JavaScript. Системная настройка уменьшения движения отключает анимацию. В существующем упрощённом оформлении остаётся обычная полоса со счётчиком. Панель не печатается с выпиской. При увеличении шапки отступ прокрутки учитывает её высоту.

Данные прогресса доступны только своему аккаунту пациента через `/api/me/diary-journey`, без текста записей и медицинских оценок. Изменения БД и миграции не нужны, исходные записи/пароли сохраняются. После обновления проекта перезапустите веб-сервер; отдельная модель или обработчик для дорожки не требуется.
