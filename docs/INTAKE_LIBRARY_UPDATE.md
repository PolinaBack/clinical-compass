# Пол, переходы анкет и библиотека врача

Ветка: `feat/local-mvp`. Это доработка уже работающих кабинетов; новая база и повторная загрузка демонстрационных данных не нужны.

## Что изменилось

У пациента: **Профиль → Обо мне → Личные данные**. Пол теперь виден среди основных вопросов. Выбор **Женский** добавляет карточку **Менструальный и репродуктивный анамнез** в группу «Психическое и телесное здоровье». Вопросы остаются добровольными; наличие менструаций или беременности приложение не предполагает.

Если пол не указан или выбран другой вариант, раздел доступен через **Дополнительный раздел о менструальном цикле → Открыть раздел о цикле** на странице «Обо мне». После сохранения ответов его карточка остаётся в анкете, даже если потом изменить пол. Существующие ответы и отправленные врачу версии не удаляются.

В конце каждого раздела появилась кнопка **Сохранить и перейти дальше**. Она сохраняет текущие ответы и открывает следующий раздел. В последнем разделе кнопка **Сохранить и проверить анкету** открывает просмотр ответов; отправка врачу по-прежнему выполняется отдельно. Можно пропускать вопросы. Семейное дерево открывается своей карточкой и сохраняет прежний вид с листьями.

У врача верхний пункт **Библиотека** открывает три карточки: **Лекарства**, **Рекомендованные ресурсы**, **Анкеты**. Поиск/импорт препаратов, назначение и отмена материалов, опросники работают в прежних разделах. **FAQ-форум** находится в самом низу страницы **Задачи**.

## Обновление и запуск в PyCharm

1. Откройте существующий проект. Если сервер запущен, остановите его сочетанием **Ctrl+C** в его Terminal.
2. В Terminal из корня проекта проверьте ветку и локальные изменения:

```powershell
git branch --show-current
git status
```

Нужна ветка `feat/local-mvp`. Если вы уже на ней, переключать ветку не нужно. Если Git показывает ваши несохранённые изменения, сначала сохраните их коммитом; команды удаления или сброса не нужны.

3. Получите опубликованное обновление:

```powershell
git pull --ff-only origin feat/local-mvp
```

Если Git сообщает о расхождении веток или конфликте локальных изменений, сохраните сообщение и разберите причину. Не используйте `reset --hard` или force push.

4. Запустите приложение с прежней базой:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

5. Откройте **http://127.0.0.1:8000**. Войдите своими прежними данными. Если оформление осталось старым, нажмите **Ctrl+F5**. Не запускайте `setup_demo`/`seed_demo` поверх своей базы.

## Простая проверка в браузере

1. У пациента откройте Личные данные, выберите женский пол и нажмите «Сохранить и перейти дальше»: откроются Медицинские измерения.
2. Вернитесь в «Обо мне», раскройте группу «Психическое и телесное здоровье»: в ней есть карточка цикла. Укажите только те сведения, которыми готовы поделиться.
3. Обновите страницу и перезапустите сервер: пол и ответы остаются. Изменение пола не удаляет уже заполненный цикл.
4. Войдите врачом: **Библиотека** содержит ровно три карточки. Проверьте их открытие, затем **Задачи** и FAQ-форум внизу.
5. В браузере можно нажать **F12 → значок телефона** и выбрать ширину 390 px для проверки мобильного вида.

Полный набор серверных проверок из Terminal:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты используют временные базы, а не ваш дневник. Результаты проверки этой версии записаны в [PROGRESS.md](PROGRESS.md).
