# Обновлённый экран анализа ИИ

26.10.2026 · U-AI-PRESENTATION-26.

Общая «Краткая сводка» находится сразу под состоянием выбранного анализа. Далее идут четыре карточки Авиандра, три показателя дневника рядом с вопросами врачу и отдельное объяснение локальной модели. Убраны указанные технические панели, ссылки на ID оснований, «Подробнее» и повторяющиеся графики анкет. Записи, источники, расчётные статусы и история в базе сохраняются.

## Обновление в PyCharm

```powershell
git switch feat/local-mvp
git pull --ff-only origin feat/local-mvp
```

Остановите и заново запустите **приложение и обработчик ИИ**. Старый работающий обработчик продолжает использовать прежние проверки ответа даже после обновления файлов.

В отдельных терминалах из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

```powershell
.\.venv\Scripts\python.exe -m scripts.patient_ai_worker
```

Ollama и установленная локальная модель должны быть доступны как раньше. Обновите страницу Ctrl+F5. Обработчик обслуживает оба запуска: общую сводку и объяснение Авиандра. Сброс БД и паролей не нужен.

## Ответ модели

- Новые формы всегда запрашивают свободный текст без проверки медицинских фраз, числа вопросов или ID фактов. Переключатель формата убран.
- Непустой текст из корректного ответа провайдера сохраняется и показывается, включая короткий ответ, отказ модели и незавершённый JSON. Для старых заданий структурированного режима неудачная проверка также оставляет исходный текст вместо отклонения.
- Ответ помечен как непроверенный. Он не меняет назначения, факты или расчётные статусы. Авторизация, согласие и доступ ведущего врача по-прежнему проверяются.
- Содержимое JSON при показе декодируется в читаемый русский текст; у известных разделов скрываются технические поля ссылок. Неизвестные поля сохраняются при отображении. Исходный ответ хранится целиком и зашифрованным. HTML не исполняется.
- Завершённый результат появляется автоматически. При сбое загрузки страницы остаётся кнопка ручного обновления.
- Если карта изменилась во время генерации, полученный текст сохраняется с привязкой к прежнему снимку. Для актуального ответа нужен новый запуск.
- При недоступной Ollama, пустом ответе или транспортном сбое остаётся конкретная ошибка: готовый текст вместо модели не подставляется. Прежние отклонённые ответы, которые старый код не сохранил, восстановить нельзя; запустите анализ заново.

Синтетическая исследовательская лаборатория вне карточки пациента сохраняет прежние строгие проверки.

## Динамика

Остались субъективная тревога, самочувствие и продолжительность сна. Все сохранённые точки соединяются: сплошная линия между соседними днями, пунктир между записями с пропусками. Пропущенные значения не заменяются нулями, промежуточные наблюдения не создаются.
