# Вложения на форумах, возраст и назначение анкеты пожеланий

26.10.2026 · U-FORUM-FILES-PROFILE-26.

## Обновление в PyCharm

Остановите приложение, получите код и запустите его заново:

```powershell
git switch feat/local-mvp
git pull --ff-only origin feat/local-mvp
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Обновите страницу Ctrl+F5. Миграция **019** автоматически создаёт две новые таблицы — вложений форума и назначений анкеты пожеланий. Прежние таблицы/записи, пациенты, пароли и назначения не удаляются. Сбрасывать БД не нужно. Перед первым запуском можно сделать копию прежней базы командой `python -m scripts.backup data/backups/before-forum-profile.db --source data/compass.db`; выберите новое имя, если копия уже существует. Сохраняйте прежние `COMPASS_DB` и ключ шифрования.

## Проверить вручную

1. **Обо мне → Лекарства и аллергии:** прежний большой выбор нежелательных эффектов и отдельный основной приоритет удалены из интерфейса. Панель «Связанные сведения» удалена из разделов и карточек анамнеза. Сами записи, связи и старые ответы сохраняются.
2. **Обо мне → Личные данные:** вопрос «Дата рождения». Введите дату: возраст сразу появится под ней и пересчитается при изменении. На сервере он рассчитывается на текущую дату по Москве, без отдельного поля возраста. Без JavaScript расчёт появится после сохранения. Будущая дата не принимается, «Не знаю» не становится возрастом 0. Врач видит возраст по отправленной версии анамнеза, а не частному черновику.
3. **Врач → пациент → Назначения → Лекарства → Пожелания о переносимости:** нажмите «Назначить анкету пожеланий по побочным эффектам». У пациента в **Профиль → Мои назначения и обследования → Лекарства** появится необязательная анкета и дата просьбы врача. До назначения формы нет, прямое сохранение тоже запрещено. Черновик остаётся личным; врач получает ответы только после отправки. После ответа можно назначить анкету повторно. Повтор одной отправки не создаёт дубликат.
4. **Форум врачей:** в новой теме, ответе и редактировании доступна одна кнопка «Прикрепить файл». Выбранные файлы сохраняются при предпросмотре, затем появляются под опубликованным вопросом/ответом. Предпросмотр и подтверждение обезличивания сохраняются. Другой врач не видит черновой файл; опубликованный доступен врачам по правам самой темы. Пациентам врачебные файлы недоступны. Повтор публикации с теми же файлами идемпотентен.
5. **FAQ:** прикрепите файл к вопросу. До модерации его скачивает только специалист. Врач может приложить файл к ответу. После публикации оба доступны в теме FAQ; после скрытия вопроса публичный доступ к ним прекращается. Анонимный вопрос и его файл не связываются с аккаунтом пациента.

Поддерживаются **PDF, PNG, JPG/JPEG и TXT в UTF-8**, до пяти файлов. Лимит на файл — прежний `COMPASS_ATTACHMENT_MAX_MB` (по умолчанию 10 МБ). Файлы хранятся зашифрованными, резервная копия учитывает ключ и для базы с одними форумными вложениями. При потере ключа новый поверх данных не создаётся. Скачивание идёт как вложение с `nosniff`, без исполнения HTML. Активные PDF и обнаруженные антивирусом угрозы не принимаются. Если антивируса нет, это честно отмечено; гарантия автоматического обезличивания файлов не заявляется. Автор проверяет содержимое, имена и метаданные перед публикацией.

Старые ответы о пожеланиях остаются в истории и доступны врачу. Они сами по себе не открывают пациенту новую форму: сначала требуется назначение. Синтетические сценарии при новом создании содержат отдельную вымышленную просьбу врача; повтор команды не назначает её существующим пациентам автоматически.

Ограничения текущей поставки: вложения нельзя редактировать на месте; для исправления публикации используются прежние действия редактирования/скрытия, содержимое файла проверяет автор. Успешная работа во всех браузерах и нативном PyCharm требует ручной проверки; последнее автоматическое подтверждение — HTTP-тесты и проверки синтаксиса, без нового браузерного прогона.
