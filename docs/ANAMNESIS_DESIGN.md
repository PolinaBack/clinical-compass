# Первичный анамнез: новое оформление

Откройте **Профиль → Обо мне**. Разделы анкеты теперь показаны пастельными карточками, как в присланном образце. Названия, вопросы и медицинское содержимое сохранены. На компьютере — три колонки, на планшете — две, на узком телефоне — одна.

Вводный текст «Иногда сложно вспомнить…» расположен перед прогрессом. Общий прогресс и прогресс разделов показывают **проценты**, рассчитанные по заполненным вопросам. Ответы «не знаю», отказ и отложенный вопрос сохраняются, но не считаются заполненным ответом. Пояснение «Кто увидит ответы и можно ли пропускать?» находится внизу страницы.

Внутри разделов основные вопросы собраны в небольшие блоки. Кнопка **«Пропустить или уточнить ответ»** раскрывает прежние варианты статуса. Дополнительные вопросы, документы и связанные карточки открываются по нажатию. Ничего из этих вопросов не удалено.

Чтобы открыть другой раздел, выберите его в списке **«Перейти к разделу»**. Текущие ответы сначала сохраняются. Кнопка **«Сохранить и перейти дальше»** также остаётся. При конфликте с другой вкладкой переход останавливается: можно скопировать последние правки и обновить страницу.

Раздел о менструальном цикле показывается **только после сохранения женского пола** в Личных данных. При другом или незаполненном поле карточки и перехода нет. Если ранее были ответы о цикле, они сохраняются в базе и снова показываются после возвращения женского пола. Старые отправленные версии сохраняют свои данные и пол.

Прежний блок свободных заметок полностью убран с экрана. Его старые записи в базе сохранены. Свободный текст в вопросах самой анкеты остаётся доступным.

## Обновление в PyCharm

1. Остановите сервер через **Ctrl+C** в его Terminal. Откройте Terminal из корня существующего проекта.
2. Проверьте ветку и локальные правки:

```powershell
git branch --show-current
git status
```

Нужна ветка `feat/local-mvp`. Если у вас есть свои несохранённые изменения, сначала сохраните их коммитом. Не используйте команды сброса или удаления данных.

3. Получите обновление и запустите приложение:

```powershell
git pull --ff-only origin feat/local-mvp
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

4. Откройте **http://127.0.0.1:8000**, войдите пациентом и перейдите в **Профиль → Обо мне**. При старом оформлении нажмите **Ctrl+F5**. Пересоздавать базу или запускать демонстрационное заполнение не нужно.

## Что проверить

1. Текст перед прогрессом, проценты вместо числа вопросов, пастельные карточки и пояснение доступа внизу.
2. В Личных данных укажите женский пол. Вернитесь к карточкам — раздел цикла появился. При другом поле он скрывается, старые ответы не исчезают из базы.
3. Измените ответ и сразу выберите другой раздел: после возвращения ответ сохранён.
4. Обновите страницу и перезапустите сервер: ответы и проценты остаются.
5. Проверьте телефон через **F12 → значок телефона**, например ширину 390 px.

Полный набор серверных проверок:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```
