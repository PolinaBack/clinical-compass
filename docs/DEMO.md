# Демонстрация (5–7 минут)

Все профили и события вымышленные. Запустите `python -m scripts.seed_demo` в пустой локальной базе для начальных данных; повторная загрузка откажется менять непустую базу.

1. Открыть роль «Пациент А». Показать дневник, график и начальную семейную схему. Добавить запись с пропуском назначения и запросом связи. Это демонстрационная отметка, конкретное лекарство не задано.
2. Заполнить первичный самоотчёт. Объяснить: это техническая анкета, не валидированный скрининг, диагноз по ней не ставится.
3. Отправить вопрос врачу. Добавить сообщение о вымышленном событии с отметкой срочного внимания.
4. В другом браузерном контексте открыть демоврача. Показать карточку, пропуск, новое сообщение и автоматически появившееся уведомление (не более 10 секунд при исправном соединении).
5. Подтвердить просмотр события, отправить ответ. Внести демонстрационное решение «Обсудить дневник на следующей встрече» с основанием «Синтетический технический сценарий» и явным подтверждением. Для показа категорий можно сохранить синтетическое решение «Демонстрация маршрутизации, не клиническая рекомендация» в категории «желательно» или «обязательно».
6. Вернуться в кабинет пациента: ответ и решение видны. Проверить, что пациент Б не видит карточку А.
7. Добавить родственника: сначала родителя, затем ребёнка со ссылкой на родителя. Показать стрелку.
8. По желанию включить голосовой ввод с вымышленным текстом, подтвердить согласие на возможную отправку аудио сервису браузера. Проверить текст и сохранить вручную. При отсутствии API показать ручной ввод.
9. Перезапустить приложение, снова выбрать роль и показать сохранённые записи.

## Обязательные сценарии с «Авиандром» — ожидают первоисточников

Кейс требует профиль пациента, рекомендации по лечению и маршрутизацию для сценариев с рассмотрением назначения «Авиандра». Текущие демопрофили не являются такими клиническими сценариями. Не утверждать, что препарат показан или безопасен для вымышленных профилей, не указывать дозировки и не имитировать медицинскую рекомендацию до проверки действующей инструкции ГРЛС и клинических рекомендаций. Перечень недостающих материалов и функций: CLINICAL_GAPS.md.
