# Обновление кабинетов и записи на консультацию

Врач открывает **Календарь → Свободное время для записи**, задаёт начало, длительность, часовой пояс (например `Europe/Moscow`), HTTPS-ссылку видеосервиса и способ связи при обрыве. Кнопка **Опубликовать свободное окно** сохраняет время в базе. Пересекающиеся окна не публикуются. Это расписание и ссылка выбранного сервиса; встроенный видеосервис этим обновлением не добавляется.

Пациент открывает **Профиль → Консультации и видеосвязь**, выбирает свободное время и нажимает **Записаться на консультацию**. Запись подтверждается сразу. Занятые, отменённые и прошедшие окна не предлагаются; если врач ещё не опубликовал время, об этом написано прямо. Весь профиль и его вкладки остаются на месте.

Здесь же ниже — **Последняя встреча → Итоги → Следующие шаги**. Пациент видит текст только после одобрения и публикации врачом. Врач видит и помеченный черновик. Для подробностей и прежних встреч раскройте **Другие встречи и подробности**. Оригинал и полная расшифровка доступны только ведущему врачу. Разрешения пациента и обязательная проверка врачом действуют как прежде.

Врач может отменить приём в его карточке: **Подготовка, завершение или отмена приёма → Отменить приём**. Будущее окно снова становится доступным; прежний приём и событие отмены остаются в истории. Пустое окно можно снять в Календаре. Для старых приёмов без длительности есть **Уточнить длительность прежних приёмов**: приложение не угадывает, сколько длится встреча.

В **Ресурсах → Назначенные материалы** появилась **Отменить назначение**. Материал исчезает из активных назначений пациента, но прежнее назначение и статусы чтения сохраняются. Назначить заново можно в той же карточке ресурса. Старые действия отменённого назначения больше не меняют состояние.

В дневнике видна одна последняя запись после заметок; прежние открываются через **Ещё записи**. В заметках действует **Ещё заметки**. Прямые ссылки на старую запись открывают нужную историю. Данные не удаляются.

Навигация пациента, помощь и выход находятся в одной строке сверху. На узком телефоне пункты представлены значками; полные названия доступны программе чтения с экрана и при наведении. Помощь остаётся одной кнопкой справа сверху. Выход — значок двери со стрелкой рядом с ней. Врачебное меню Ещё удалено; анкеты, лекарства и FAQ доступны со страницы Ресурсы. Отдельного раздела рисков/нежелательных явлений/решений больше нет; клинические алерты и подтверждение результатов врачом работают.

## Как обновить проект в PyCharm

Остановите приложение и обработчик встреч в их терминалах через **Ctrl+C**. В Terminal PyCharm, из папки проекта, создайте резервную копию:

```powershell
.\.venv\Scripts\python.exe -m scripts.backup data\backups\before-consultations-update.db
```

Если файл уже есть, выберите другое имя. Рядом с копией сохраняется ключ вложений, если он используется; храните их вместе.

```powershell
git status
git switch feat/local-mvp
git pull --ff-only origin feat/local-mvp
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

`git status` показывает ваши локальные изменения. Если Git остановит переключение или обновление из-за них, сохраните их отдельным коммитом; не используйте принудительный сброс. Если ветка уже feat/local-mvp, повторное переключение не нужно.

При запуске приложение само добавит новые таблицы/поля в прежнюю SQLite. Существующую базу не удаляйте и демонстрационное заполнение поверх неё не запускайте. Откройте http://127.0.0.1:8000. Достаточно обычной перезагрузки страницы: стили имеют автоматические версии.

Для настоящей расшифровки запустите в отдельной вкладке Terminal:

```powershell
.\.venv\Scripts\python.exe -m scripts.meeting_worker
```

Проверки проекта:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Проверьте два входа по очереди: врач публикует окно в Календаре; пациент записывается через Профиль, видит подтверждённое время и только одобренные итоги; врач отменяет материал, после обновления пациент больше не видит активного назначения. Для проверки телефона в браузере нажмите **F12 → значок телефона** и выберите ширину 390 или 320. Проверки в облаке выполняются в Linux/Chromium; настоящий Windows и качество ваших локальных моделей отдельно здесь не проверяются.
