# Стартовая страница и добавленные лекарства

26.10.2026. При открытии `http://127.0.0.1:8000/` показывается страница с присланного изображения: «Не обязательно справляться в одиночку», дневник справа, две кнопки выбора роли. Она остаётся стартовой и при сохранённой сессии пациента. Автоматического перенаправления с `/` в дневник больше нет. Ввод логина/пароля и текущие кабинеты сохранены.

В библиотеке врача можно сохранить неполную карточку, включая название из одного слова, без обязательного МНН. Если сайт не отдал часть полей, они остаются неизвестными. При отсутствии названия используется подпись «Лекарство без названия». Проверка на совпадение названия с другим препаратом не блокирует новую карточку; повторная отправка одной и той же формы остаётся идемпотентной.

В добавленных карточках есть блок «Ресурс» с полной ссылкой на исходную страницу. Для ручного ввода без ссылки указано, что данные внесены вручную. Там же автор карточки может раскрыть удаление и нажать «Удалить из библиотеки».

Удалённая карточка исчезает из каталога, подсказок, поиска и выбора новых препаратов. Старые назначения/отправленные схемы/сообщения о реакциях и версии не уничтожаются. В них сохраняются прежние название, форма и дозы; карточка по старой ссылке имеет пометку удаления. Редактирование уже сохранённого назначения остаётся доступным. Добавить удалённый препарат в новую карту нельзя. Исходные карточки и записи другого автора не удаляются.

Обновление в PyCharm, ветка `feat/local-mvp`:

```powershell
git pull --ff-only origin feat/local-mvp
```

Перезапустите приложение, откройте `/` и нажмите Ctrl+F5. БД и пароли не сбрасывайте; новых миграций нет.

Проверьте вручную:

1. Начальную страницу и обе кнопки выбора роли, в том числе после входа пациентом и повторного открытия `/`.
2. Добавление лекарства с однословным названием и пустым МНН.
3. Получение данных по доступной HTML-ссылке, сохранение неполного результата, блок «Ресурс» и переход по ссылке.
4. Удаление своей добавленной карточки: её нет в поиске и выборе новых препаратов, прежние назначения остаются.

Чтение сайтов по-прежнему использует настоящий HTTPS-запрос и HTML-разбор. Динамические/защищённые страницы могут отдать только часть данных; сохранение не превращает их в подтверждённую официальную инструкцию или автоматические правила ИИ. Полнота чтения конкретного реального сайта здесь не подтверждалась.
