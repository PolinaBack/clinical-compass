# Карточка и пожелания пациента при выборе препарата

25.10.2026 · U-MEDICINE-PICKER-25. Изменения в **Пациенты → карта → Назначения → Лекарства → Добавить препарат из списка**.

У каждого препарата рядом с «Добавить» есть кнопка **Карточка** и результаты автоматической сверки всех выбранных пациентом эффектов. Проверка появляется до добавления препарата в схему. Главный приоритет отмечен звездой; показаны название эффекта и система органов. Поиск препаратов сохраняет эти результаты.

Карточка открывается в новой вкладке: несохранённые поля схемы в исходной вкладке остаются на месте. Ссылка возврата и кнопка «Назначить пациенту» в карточке относятся к выбранной карте, включая вторую и последующие карты.

## Что рассчитывает алгоритм

Сервер берёт последнюю явно отправленную анкету пожеланий из лекарственного раздела или отправленного первичного анамнеза. Частные черновики и пожелания другой карты не участвуют. Затем для каждого препарата сверяет выбранные эффекты с текущим реестром реакций:

- **Есть в реестре** — совпали медицинский термин и система органов.
- **Термин найден в другой системе … требуется сверка** — медицинский термин совпал, но система отличается. Такая запись не теряется и не превращается в «не найдено»; она не считается точным совпадением.
- **В реестре не найдено** — записи с этим медицинским термином для препарата нет. Это не утверждение, что препарат не вызывает этот эффект.
- **Нет данных о реакциях этого препарата / недостаточно данных** — для препарата в реестре нет записей; отсутствие сведений не выдаётся за отрицательный результат.
- **Нет выбранных эффектов для проверки** — пациент ещё не выбрал и не отправил эффекты либо отправил пустой выбор.

Проверка выполняется при открытии/обновлении назначений. После новой отправки пожеланий обновите страницу врача. При сохранении схемы прежний механизм заново сохраняет текущие отправленные пожелания и точные совпадения в её неизменяемом снимке. Старые версии схем не пересчитываются новыми ответами; новый список кандидатов в просмотре истории не показывается.

Это реальная программная сверка справочника, без вызова ИИ и заранее подготовленных пациентских результатов. Свободный комментарий пациента доступен врачу, но не превращается в коды эффектов автоматически. Синонимы и похожие термины не объединяются автоматически. Алгоритм не предсказывает индивидуальную вероятность, не оценивает противопоказания по пожеланиям и не подбирает/ранжирует препараты. Назначение и доза остаются ручными.

## Обновление в PyCharm

Остановите сервер и выполните в терминале корня проекта:

```powershell
git switch feat/local-mvp
git pull --ff-only origin feat/local-mvp
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

Сохраните прежнее значение `COMPASS_DB`, если оно задано. Обновите браузер Ctrl+F5. Для этой доработки нет новых миграций; база, пароли, прежние ответы и схемы не очищаются.

## Ручная проверка на вымышленной карте

1. Пациент: **Профиль → Мои назначения и обследования → Лекарства**, выберите до трёх эффектов, главный и нажмите **Отправить ответы специалисту**. «Ответить позже» оставляет личный черновик, который не должен появляться у врача.
2. Врач в отдельном браузере: откройте ту же карту, назначения и список добавления препаратов. До добавления уже видны результаты по каждому эффекту и звездочка главного. Без отправленных пожеланий показано отдельное пустое состояние.
3. Для проверки трёх разных результатов можно выбрать «Тошнота» (ЖКТ), «Сонливость» (Психика и сон) и «Бронхоспазм» (Дыхательная система). Для D01 текущий справочник даёт точное совпадение тошноты, сонливость в другой системе и отсутствие записи бронхоспазма. Это проверка содержимого неполного справочника, а не клиническое заключение.
4. Найдите препарат поиском, нажмите **Карточка**. Она откроется в новой вкладке. Внесённая доза в прежней вкладке должна остаться; сам просмотр не сохраняет и не меняет схему.
5. Повторите со второй картой. В карточке препарата возврат и «Назначить пациенту» должны вести во вторую карту, а её пожелания не должны копироваться из первой.
6. Добавьте препарат, заполните дозу/кратность и сохраните. После перезагрузки схема и сопоставления остаются. Измените пожелания у пациента, отправьте и обновите врача: новый список показывает новые ответы; прежняя сохранённая версия схемы остаётся с прежними пожеланиями.
7. Без JavaScript результаты и карточки доступны. Сначала сохраните текущий черновик, затем откройте карточку и используйте **Назначить пациенту**; заполните поля и сохраните обычной кнопкой.
