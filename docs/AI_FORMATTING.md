# Форматирование ИИ-анализа

Свободные ответы и прежние структурированные результаты обоих анализов отображают Markdown: выделение жирным/курсивом, заголовки, списки, цитаты, код и таблицы. Исходный ответ в защищённой истории не меняется. HTML модели экранируется; активные схемы ссылок запрещены Markdown-парсером, изображения выводятся подписью без загрузки внешних ресурсов. Это обработка отображения, без новой проверки медицинского содержания или отклонения ответа.

В подтверждении четырёх направлений Авиандра «Основание проверки» необязательно; короткий комментарий также разрешён. Выбранный результат и явное подтверждение врача по-прежнему необходимы. После сохранения сразу обновляется цвет всей карточки без перезагрузки страницы. Другие незавершённые формы сохраняются. Реальные найденные противопоказания и риски сохраняют красный цвет. Проверка относится к текущей версии карты/библиотеки; при изменении данных требуется новая проверка. Требования к подтверждению регистрации лекарства в библиотеке не меняются.

Объяснение локального ИИ расположено отдельной панелью на всю ширину анализа, под динамикой и вопросами врачу. На небольшом экране занимает доступную ширину; широкая таблица/код прокручиваются внутри ответа.

После получения изменения установить обновлённые зависимости командой `python -m pip install -r requirements.txt` (добавлен `markdown-it-py==4.0.0`) и перезапустить веб-приложение. Обработчик Ollama использует прежний протокол, модель/настройки менять не нужно.

Проверка браузера — `scripts/browser_ai_formatting.py` на отдельной синтетической БД; результаты в `docs/reviews/ai-formatting/`. Рабочая БД, входы/пароли, права доступа и исходные 806 строк требований сохранены.
