# Записи календаря и поиск по расшифровке

Встреча сначала показывает свёрнутые строки «Запись 1», «Запись 2» и далее. Номер относится к этой встрече, а не к общему ID базы; новая загрузка добавляется в конец и не меняет номера предыдущих записей. Внутри строки остаются файл, обработка, расшифровка, итоги, редактирование и история. После редактирования/запуска обработки открывается именно нужная запись; прямые ссылки на фрагменты также раскрывают её. Без JavaScript строки раскрываются стандартными средствами браузера.

Врач может искать слово/фразу в текущей и исторической расшифровке. Поиск не учитывает регистр, лишние пробелы и различие е/ё; фраза может пересекать границу соседних фрагментов. Показаны номер/число совпадений, контекст с выделением, кнопки перехода назад/вперёд и сброс. Enter переходит к текущему совпадению. В редакторе выделяется соответствующий участок текста; поиск учитывает несохранённые правки, ничего не меняет и не сохраняет. Поисковая фраза не отправляется на сервер. У пациента полной расшифровки и её поиска нет.

В выводе итогов удаляются дословно повторяющиеся пункты и предложения, включая различия регистра/пробелов/конечной пунктуации утверждений. Одинаковое действие остаётся в «Следующих шагах», а не дублируется в пересказе. Вопрос не объединяется с утверждением. Разные отрицания, числа, дозы и даты не объединяются; короткие контекстные реплики и сокращения не вырезаются из абзацев. Частично совпадающие предложения из разных исходных цитат/фрагментов сохраняются, чтобы не смешивать разные обстоятельства. Модель дополнительно получает указание не повторять одну мысль в разных разделах. Синонимические выводы не считаются одинаковыми автоматически. Исключённые/частные пункты не подавляют публичный текст.

Новые автоматические итоги сохраняются без повторов. Уже существующие итоги отображаются без повторов в календаре и сводке профиля; их исходный текст, источники, публикации и редактор остаются в истории без перезаписи. Расшифровка и запись не изменяются. JSON-скачивание и адрес `/meeting-recordings/{rid}/export` удалены; внутреннее обновление статусов по JSON сохранено.

Миграция/повторная загрузка медиа не нужны. После получения кода перезапустить веб-приложение и `python -m scripts.meeting_worker`, чтобы новые задачи использовали обновлённую версию подготовки итогов. Обработка остаётся локальной; права, согласия, публикация только после решения врача и сроки хранения сохраняются.
