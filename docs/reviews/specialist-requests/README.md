# U-SPECIALIST-REQUESTS-24: запросы врача, календарь и конструктор

24.10.2026, базовый коммит `e1630e3`, ветка `feat/local-mvp`. [Инструкция](../../SPECIALIST_WORKSPACE.md), [файлы](FILES.md).

## Поведение

Зелёная сводка «Что важно уточнить», четыре кнопки «Запросить у пациента». Запросы только по своей карте; незавершённый повтор того же типа не дублируется. Пациент видит просьбу в профиле/анкетах и на карточке соответствующего раздела. Черновик остаётся частным. Ответ учитывается только после явной отправки соответствующих сведений; неизвестное и отрицательное остаются такими ответами. Уже актуальные сведения можно явно отправить повторно без создания новой версии того же анамнеза. Для запроса пожеланий/скрининга учитываются также опросники, уже назначенные и незавершённые на момент запроса; готовые тесты не назначаются повторно.

Календарь открывается с 08:00; к ночным часам можно прокрутить вверх. Три одноцветные кнопки ниже сетки, без раскрывающейся кнопки и списка выбора действия. Начало и окончание независимы, переход через полночь отмечается явно. Прежние клиенты с длительностью поддерживаются; передавать одновременно окончание и длительность нельзя. Сохраняются часовые пояса, занятость, повторные отправки и ограничения 5–240 минут.

Конструктор показывает параметры выбранного формата и живой пример всех 11 типов. Скрытые параметры выключены при отправке, пробный ответ не сохраняется. Условие и порог объединены одним списком. Поле порядка удалено из интерфейса, старое положение вопроса и нестандартные пороги сохраняются. Смена формата создаёт новую версию, старые ответы не переписываются.

Миграция 013 добавляет отдельную таблицу запросов и индекс одного незавершённого запроса на тему/пациента. Существующие таблицы и их строки не переписываются. Утилита явного сброса учебных анкет учитывает новые FK: только выбранные исходные демо-карты, с полной резервной копией; другие карты и запросы сохраняются. Сам сброс на рабочей базе не выполнялся.

## Ручная проверка

1. Обновите ветку и перезапустите сервер, не сбрасывая базу. Врач → пациент → личный профиль → зелёная сводка. Запросите лекарства.
2. Войдите пациентом, откройте профиль → «Обо мне»: появится просьба врача с переходом к лекарствам. Заполните ответ. До отправки запрос остаётся незавершённым, врач не видит черновик. Отправьте анкету и проверьте состояние кнопки у врача. Повторите с аллергиями; ответ только о лекарствах не закрывает просьбу об аллергиях.
3. В календаре проверьте 08:00, прокрутку вверх и три кнопки. Создайте окно без ссылки с собственным окончанием, затем встречу со ссылкой. Измените окончание, после этого начало: выбранное окончание сохраняется. Для перехода через полночь используйте отметку следующего дня.
4. В конструкторе переключайте шкалу, число, выбор, текст, дату/время и файлы. Проверьте изменение примера/параметров, сохраните вопрос, войдите пациентом и ответьте. Измените формат у врача и убедитесь, что прежняя запись дневника сохраняет старую версию.

## Пределы

Просьба отображается внутри приложения при открытии/обновлении страниц; это не push/email/SMS. Нативные элементы времени/даты зависят от браузера и операционной системы; Windows/PyCharm здесь не запускались. Реальные Whisper/Ollama этой задачей не менялись и не вызывались. Файл/голос в примере конструктора не запускает запись микрофона и не загружает данные.
