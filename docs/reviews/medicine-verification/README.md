# Проверка допуска препаратов к назначению

27.10.2026 · U-MEDICINE-VERIFICATION-27 · `feat/local-mvp` поверх `b872c1d`.

Добавление по ссылке и сохранение неполного/длинного текста сохранены. Статус допуска рассчитывается отдельно от наличия карточки, извлечённого РУ и отдельно проверенных официальных фрагментов. Подтверждение врача в карточке содержит реквизиты формы, регистрацию в РФ, ссылки/редакцию инструкции, шесть разделов с локаторами и отметками, дату, срок и основание. Решения неизменяемы и относятся к версии карточки. Отзыв/срок/смена карточки закрывают новое использование.

Проверки на сервере охватывают добавление в схему по ссылке, оба POST-адреса сохранения и новую отправку пациенту. Снимок схемы связан с конкретным решением проверки; после повторной проверки требуется пересохранение. История и уже отправленные схемы не переписываются.
