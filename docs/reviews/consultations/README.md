# Приёмка U-CAB-23

Проверки выполнялись на Linux/Python 3.12 и Chromium. Все браузерные аккаунты, дневники, встречи, видео и ресурсы — синтетические, в отдельных временных базах. Настоящие Whisper/Ollama не запускались: обработчик использовал явно заданный SyntheticModels. FFmpeg, сохранение видео, плеер, права, публикация/отзыв, очередь и прогресс работали через настоящее приложение.

- `browser-consultations.txt`: календарь → опубликованное окно → запись из профиля → отмена/освобождение; единые вкладки/одобренные итоги; последние дневник/заметка и история/прямая ссылка; отмена материала; выход; все элементы шапки в одной строке и видны на телефоне; клавиатура, режим без декора, обе роли при 320/390/768/1280 px.
- `browser-regression.txt`: прежние маршруты двух кабинетов, анкеты и события безопасности, дневник/компас/сон, семейное дерево, настройки E01, лекарственная библиотека/Excel/сочетания.
- `consultations-accessibility.json`, `meetings-accessibility.json`, `e02-accessibility.json`, `diary-modal-accessibility.json`: 50 проверок страниц/диалогов axe WCAG A/AA, 0 нарушений. Это автоматические проверки, а не заявление о полной ручной сертификации доступности.
- `data-check.json`: резервная копия настоящей облачной SQLite, миграция 010 и два запуска на копии, затем рабочая база. Сравнивались все старые поля каждой строки 69 прежних таблиц; 541 строка данных и 9 прежних записей миграций сохранены. Содержимое встреч/профилей в отчёт не включено. Целостность и внешние ключи проверены. Backup хранится вне Git.
- Скриншоты показывают мобильную/компьютерную шапку, дневник, календарь, единую вкладку и одобренные итоги. Текст «Обсуждался сон» — синтетический результат для проверки, а не оценка качества настоящей модели.

Текущий набор проверок дополняет прежние 806 требований; расписание не объявляется готовым видеосервисом, а исчезновение отдельной вкладки рисков не отключает клинические алерты. История удалённых из интерфейса разделов сохранена.
