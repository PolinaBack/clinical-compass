# Стартовая страница и жизненный цикл добавленных карточек

26.10.2026 · U-LANDING-MEDICINE-CARDS-26. [Инструкция](../../LANDING_AND_MEDICINE_CARDS.md).

Финальный прогон: **9 passed**, одно прежнее предупреждение Starlette/AnyIO, 28,28 с. Команда: `.venv/bin/python -m pytest -q tests/test_medicine_card_lifecycle.py tests/test_public_entry.py tests/test_doctor_medicines.py::test_library_structure_and_removed_pages_have_no_dead_ui_links`.

Проверены однословное название/отсутствие МНН при разборе страницы и сохранении; отсутствие вымышленных данных в пустых полях; видимый ресурс и кнопка удаления; удаление/повтор; запреты для другого автора/пациента/неверного CSRF и исходного препарата; исчезновение из каталога/подсказок/нового выбора; сохранность исходных строк и отправленных схем; продолжение редактирования прежнего назначения с прежним снимком; независимая сессия с ранее выбранным препаратом; целостность/FK. Стартовая страница остаётся на `/` с двумя входами даже при активной сессии пациента. Входы и текущая библиотека работают.

Предыдущий расширенный прогон охватил 96 случаев, из них 94 прошли. Два сбоя были связаны с неверной передачей контекста видимости удаления; исправлены и включены в финальный прогон. Полный повтор 96 случаев после исправления не выполнялся. Браузер дошёл до создания неполной карточки и ссылки ресурса на пяти ширинах, но остановился на отсутствовавшей тогда кнопке; после исправления финальный сценарий удаления проверен HTTP-тестами, новый полный браузерный прогон не завершён. Скриншоты здесь показывают только стартовую страницу, не изменявшуюся после исправления кнопки.

Рабочая БД побайтно сохранена; аккаунты, пароли, прежние пациенты и назначения не изменены. Нет новой миграции; все 806 исходных строк и ячеек требований сохранены. Разбор использовал явно синтетическую страницу/HTTP-транспорт. Полнота чтения конкретного внешнего медицинского сайта и нативный Windows/PyCharm не подтверждались.
