# Экспериментальный ИИ только на синтетических данных

U-EXPERIMENT-AI-24, 24.10.2026. Отдельный раздел врача `/doctor/experimental-ai`, отдельная SQLite `data/experimental_ai/demo.db`. Кодовая фабрика создаёт Марию Соколову, 30 дней и шесть анкет. Настоящие пациенты не выбираются, карты/файлы/свободный текст не принимаются. Перед вызовом модели весь входной набор сверяется с встроенным сценарием; одной отметки synthetic недостаточно.

Реализованы описательные расчёты/графики, настоящий loopback HTTP-адаптер Ollama, постоянная очередь, heartbeat, различимые ошибки/повтор/история, схема сводки/гипотез/вопросов с основаниями, версия модели/инструкции/данных/запроса, реестр проверяемых материалов, отдельная накопительная экспертная рубрика и экспорт. Клинические записи/назначения не изменяются. В модуле нет поля выбора препарата/дозы и подстановки готового ответа при недоступности модели.

**Существенные ограничения:** настоящий запрос здесь вернул **provider_unavailable** — Ollama в окружении недоступна. [Журнал настоящего запроса](real-ollama.txt). Успешный контракт/отображение проверены только транспортной фикстурой, которая явно обозначена и в UI, и в provenance. [Скриншот помеченной фикстуры](mock-labelled-1280.png) не является свидетельством настоящей генерации. Качество, скорость и устойчивость реальной модели на ПК пользователя ещё предстоит проверить.

Внешние NICE/NHS недоступны: [проверка официального источника](official-source-check.txt). Подтверждённых документов **0**; ссылки показываются кандидатами и не включаются моделью в доказательства. Код получения/раздельного подтверждения точной версии, отпечатки и дата проверки реализованы; проверка их поведения использует технический HTTP-образец, а не выданный за официальный документ. Поиск ограничен фиксированным каталогом. Семантическая достоверность текста и полнота фильтра запрещённых утверждений не доказаны; клиническая валидация не проводилась.

Уточнение по Авиандру: добавлен нейтральный справочный переход. Запрошенное заранее заданное лекарственное предпочтение не реализовано; действующая инструкция в этом эксперименте не подтверждена. Модель не получает этот переход как доказательство и не выбирает препарат.
