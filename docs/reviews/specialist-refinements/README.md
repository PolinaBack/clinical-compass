# U-SPECIALIST-REFINE-24: уточнения кабинета специалиста

Базовый коммит `8c70bc9`, ветка `feat/local-mvp`, 24.10.2026. [Инструкция и ручные сценарии](../../SPECIALIST_WORKSPACE.md), [файлы](FILES.md).

## Что изменено

Лента последних действий над карточками и сортировка по активности ведущего врачу пациента; дата дневника берётся по сохранению, у прежних записей без времени показывается только дата. Учитываются анкеты, пояснения, заметки, дневник, отправленный анамнез и прочитанные назначенные материалы; текст частных заметок и неотправленный анамнез в ленту не выводятся. Список отделён от навигации отступом.

Сетка 24 часов без внутренней вертикальной прокрутки; часовые ячейки, минуты в форме с шагом 5. Под календарём два явных действия. Свободные часы не требуют ссылки, назначение будущей встречи требует HTTPS-ссылку и резервный контакт, в том числе при занятии ранее созданного окна. Убраны пояснительный блок обработки и нижние события/сообщения. Форумы получили свою иконку и одинаковые по цвету/расположению кнопки.

Убраны предложения форм, раскрытие отмеченных действий и кнопка повторной PHQ-4. Вместо этого после отправки PHQ-4 в той же сессии добавляются PHQ-9 при PHQ-2 ≥ 3 и GAD-7 при GAD-2 ≥ 3. Каждая пара вопросов проверяется независимо, черновик не запускает добавление, новые формы пустые. Существующие формы/ответы не заменяются; при старте правило применяется к ранее отправленным PHQ-4, без дублей. При последующем снижении результата прежние формы не удаляются.

## Пределы проверки

Лента обновляется при открытии/обновлении страницы; это последние действия, а не система доставки уведомлений. Часы без ссылки доступны врачу; самостоятельная запись пациента возможна в окно с уже подготовленной ссылкой. На телефоне неделя прокручивается горизонтально, можно переключить на день. Внешней синхронизации календаря и перетаскивания нет.

Локальные Whisper/Ollama, их скорость и качество этой задачей не менялись и не запускались. Добавление форм — программное правило по результатам опросника, не ИИ-диагноз и не назначение лечения. Windows/PyCharm проверяются пользователем по инструкции; автоматические проверки проведены в Linux/Chromium.
