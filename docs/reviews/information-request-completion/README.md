# Закрытие запроса после сохранения раздела

Позднее уточнение пользователя заменило отметку получения и ссылку одной активной сиреневой кнопкой для повторного запроса. Актуальное поведение: [повторный запрос](../information-request-repeat/README.md). Ниже сохранён протокол прежней версии.

27.10.2026 · U-INFORMATION-REQUEST-COMPLETION-27.

Основной целевой прогон: **22 passed, 1 warning, 168,85 с** (`tests/test_information_request_completion.py`, `tests/test_specialist_requests.py`, `tests/test_intake.py`). После уточнения проверки JSON-автосохранения карточек и объединения снимков: **10 passed, 1 warning, 81,32 с** — все семь новых сценариев и три прежних сценария запросов. Полный повтор первого набора после уточнений не выполнялся. В совокупности 24 разных случая. Предупреждение — прежний deprecated alias Starlette/AnyIO.

Семь новых HTTP-сценариев проверяют передачу только запрошенных ответов, сохранение ранее опубликованного при частичном обновлении, исключение приватных личных/медицинских/аллергических черновиков и связей, разграничение лекарств/аллергий, отсутствие отправки при JSON-автосохранении раздела и карточки. Также проверены последующая полная отправка без потери частных изменений, неизменность прежнего снимка, повторное подтверждение без дубликата, пустой ответ, чужой пациент, незалогиненный доступ и CSRF. Прежние проверки подтверждают разграничение запросов, сохранность после рестарта, ожидание назначенных опросников, отправку неизменившихся сведений и базовую публикацию анамнеза.

Chromium на отдельной синтетической базе прошёл полный путь. У пациента одновременно запрошены лекарства и аллергии. Автосохранение ответа «Нет» не передаёт его врачу; явное сохранение раздела закрывает лекарства и оставляет аллергию. Не закрывая вкладку врача, получаем отметку «Ответ получен» без кнопки. Старая вкладка пациента удаляет только закрытый запрос. Автосохранение новой карточки реакции остаётся личным; после явного сохранения закрывается второй запрос и удаляются все прежние метки. Личный черновик имени остаётся недоступен врачу. После перезапуска статусы/снимки сохраняются. 320/390/768/1440 px без переполнения, ошибок JavaScript нет. [Протокол браузера](browser.json).
