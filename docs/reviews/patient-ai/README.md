# ИИ-анализ любой доступной врачу карты

U-PATIENT-AI-24, 24.10.2026. Уточнение пользователя снимает ограничение новым анализом только одного вымышленного сценария. Кнопки доступны у каждой карты врача и во вкладке «ИИ-анализ». Сервер собирает фактические сохранённые сведения этой карты, включая ручной ввод и комментарии врача, и передаёт их предобученной локальной Ollama. Мария остаётся отдельной защищённой лабораторией; её сценарий и готовые ответы не подставляются в остальные карты.

Вход: профиль/возраст/пол из отправленной анкеты, 30-дневный календарный дневник, последние анкеты и их состояния, заметки/сообщения/комментарии, отправленный врачу анамнез и уточнения, семейные сведения и прежние самоотчёты. Частный черновик не читается. Содержимое файлов не распознаётся. Контекст ограничен с явным предупреждением о неполноте. Ноль и пропуск различаются; значимые исходные ответы о безопасности видны отдельно от генерации.

Сводка/гипотезы/вопросы создаются настоящим HTTP-запросом модели, с проверяемыми основаниями и снимком. Новые ручные изменения меняют снимок; при изменении во время генерации результат не выдаётся за актуальный. Нет автоматического дообучения, назначения препарата/дозы, изменения данных карты или публикации пациенту. История, очередь/heartbeat/повтор, ошибки и provenance сохранены. Снимки и результаты зашифрованы существующим механизмом ключей; backup сохраняет ключ также при наличии только ИИ-снимков.
