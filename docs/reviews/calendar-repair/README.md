25.10.2026, исходный коммит `625b797`, ветка `feat/local-mvp`. [Инструкция](../../SPECIALIST_WORKSPACE.md), [изменённые файлы](FILES.md).

## Исправление

Причина сжатой вертикальной подписи: правило ширины обычных полей распространялось на чекбокс. Чекбокс следующего дня заменён отдельной датой окончания. В открытой форме четыре обычных поля начала/окончания и отдельная строка пациента; остальные чекбоксы календаря имеют фиксированную ширину 18 px, текст получает оставшееся место.

Пределы 5–240 минут убраны из создания, старых форм и API календаря. Можно сохранять длительные/многодневные встречи и свободные окна, а также короткий минутный интервал. Окончание должно быть позже начала; сохраняются корректность даты/часового пояса и занятость. Переполнение представимой даты обрабатывается как 422 без записи в БД. Старые запросы с `duration_minutes` и отметкой следующего дня поддерживаются. Многодневная встреча показана на каждом дне; в выбранной встрече видны полные даты начала/окончания. Проверяются и прежние встречи без длительности внутри длинного интервала, а не только его крайние дни.

На HTML-ошибках кнопка «Назад» использует исходный раздел. У календаря сохраняются период/вид, пациент, режим, даты и время формы. Когда история соответствует источнику, используется обычный возврат браузера; в остальных случаях — проверенный локальный адрес. В адрес не включаются видеоссылка, резервный контакт и CSRF. Другие несохранённые значения браузер может не восстановить: их нужно проверить перед повторной отправкой. HTTP-, валидационные и обычные неожиданные ошибки имеют такой возврат; диагностический текст неожиданной ошибки не показывается пользователю.

Новой схемы/миграции нет, старые записи не переписываются. Источник последней страницы хранится в подписанной сессии с ограничением размера, внешние/небезопасные адреса возврата отбрасываются. Никаких новых данных в localStorage не записывается.

## Ручная проверка

1. Обновите ветку, перезапустите сервер и нажмите Ctrl+F5. В календаре откройте по очереди свободные часы, назначение встречи и запись прошедшей встречи. Поля не должны растягиваться, текст — превращаться в колонку букв.
2. Сохраните свободное окно, например 09:00–18:00. Назначьте встречу на другой диапазон дольше четырёх часов, затем на несколько дней. Для будущей встречи ссылка остаётся обязательной.
3. Выберите конкретный день/пациента, попробуйте сохранить пересекающееся время. На ошибке нажмите «Назад»: вернётесь в этот календарь и форму. Исправьте время и повторите.
4. Откройте подготовку выбранной встречи: чекбоксы и подписи должны оставаться обычного размера. Проверьте узкое окно браузера.

## Пределы проверки

Длительность измеряется целыми минутами; технически даты должны представляться используемым календарём. Это не снимает проверки занятости. Нативные элементы даты/времени зависят от браузера/ОС. Windows/PyCharm здесь не запускались. Если исходной страницы нет ни в форме, ни в переходе, ни в текущей сессии, используется обычный вход в кабинет. Внешняя синхронизация и модели Whisper/Ollama не менялись и не запускались.
