# Сброс двух видов демо-анкет

Пользователь подтвердил оба раздела: опросники и первичный анамнез «Обо мне». Добавлена отдельная CLI-команда `scripts.reset_demo_forms`. По умолчанию она только показывает план. При `--apply` сбрасывает данные только известных демо-профилей 1/2 с проверенными именами/логинами, после полной согласованной копии базы и ключа, проверки расшифровки и сравнения отпечатка. При активном ИИ, чужой связи, подмене идентичности или конкурентной правке операция не применяется. Сброс выполняется одной транзакцией; автоматического запуска нет.

Область: ответы/комментарии/история и медиа опросников, старые самоотчёты, первичный анамнез/версии/файлы/уточнения/прежние поля профиля и ИИ-снимки выбранных демо-карт. Назначения опросников остаются черновиками. Аккаунты/настройки/согласия, дневник/его файлы, сообщения, отдельное дерево, консультации/записи встреч и другие пациенты сохранены.
