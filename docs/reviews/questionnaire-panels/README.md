## Результат

- Голос всех пяти шкал перенесён внутрь «Добавить комментарий или обсудить», вместе с сохранённой записью и удалением. Отдельная нижняя панель удалена. Явные владельцы форм сохраняют независимые POST ответов/аудио, без вложенных form и блокирования обычного ответа обязательными аудиополями.
- «Исходные ответы» у пациента и врача свёрнуты; ссылка на вопрос раскрывает их. Отметка «Отправлено» крупная зелёная, остаётся статусом без дополнительного подтверждения.
- Возраст первичного анамнеза считается на текущий день по Москве. Будущая консультация и старый `as_of` из GET/POST не меняют дату. Панель выбора даты удалена, ИМТ в измерениях сохраняется, возраст доступен в сводке. Периоды опросников не изменяются.
- Единственная форма файлов/голоса находится внутри «Нужно что-то добавить?» в разделах и сохранённых карточках записей. Ссылки раскрывают её и фокусируют нужный контрол. Файлы, просмотр, метаданные, подтверждённое удаление и приватность отправленных версий сохранены.
- Панель «Если сейчас нечего добавить» с общими кнопками удалена из HTML и обработчиков; покомпонентные неизвестные ответы и нижнее сохранение/переход остаются. Связанные сведения перенесены ниже поддержки.
