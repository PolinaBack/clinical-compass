# Проверка сезонного пути пациента

26.10.2026 · U-PATIENT-JOURNEY-26.

Основной целевой прогон: **27 passed, 1 failed, 1 warning, 39,69 с**. Единственная ошибка была в преждевременном округлении процента до пяти знаков — проверка точного равного шага отличалась от допуска на границе. Округление убрано; после этого обе проверки подсчёта/равных шагов/цели прошли: **2 passed, 1 warning, 3,76 с**. [Начальный журнал](pytest.txt), [окончательная проверка счётчика](pytest-final.txt). Полный прогон после этой точечной правки не повторялся. В совокупности проверены 28 разных случаев: 17 новых проверок (включая 12 месяцев), четыре регрессии дневника, две оформления/навигации и пять выписок. Предупреждения — прежний deprecated alias Starlette/AnyIO.

Проверены счётчик уникальных сохранённых дат, независимость от оценки/лечения, повторные записи, пропуски/смена сезона, цель 90 и завершение, игнорирование будущих/некорректных дат, разные пациенты/роли/незалогиненный доступ, отсутствие текстов дневника в API, сохранность после рестарта. Дневник сохраняется на московскую дату при переходе через полночь UTC. Переключение вкладок не теряет счётчик; главная/входы/врач не получают панель; минимальный вид сохраняет число.

Окончательный Chromium-прогон прошёл: верхняя панель выше навигации, четыре сезонных CSS-состояния, 320/390/768/1440 px без переполнения и ошибок JS/ассетов. Настоящая форма дневника продвинула человечка на один шаг; незаписанные поля и повтор даты не продвинули. Два шага различаются только округлением экранных субпикселей (погрешность менее 0,15 px). Проверены фоновое обновление из собственного API, офлайн с последним сохранённым числом, системное уменьшение движения, упрощённый вид, работа без JS и скрытие при печати. Отдельный axe WCAG A/AA аудит панели — без нарушений. [browser.json](browser.json). Четыре сезона на изображениях проверялись переключением CSS-состояния; автоматический выбор по календарю проверен сервисными тестами, физического ожидания смены сезона не было.
