# Восстановление дерева и добавление через листья

Визуальный источник найден до изменения приложения: `43bbc4a:app/templates/family_block.html` и `43bbc4a:app/static/style.css`. Сохранены исходная SVG-геометрия кроны, изогнутые ветви, маленькие декоративные листья и форма листиков. Мягкий фон и зелёные оттенки соответствуют новому прямому пожеланию пользователя. Размещение дополнительных листьев расширяет крону, не требует заполнения предков и не заменяет её обычным генеалогическим графом. Медицинская родословная врача остаётся отдельным представлением тех же данных.

| Сценарий пользователя | Фактическая проверка |
|---|---|
| Пустое красивое дерево, понятное добавление | Крона/ветви из Git, свободные листья, центральный +; GET не создаёт relatives; empty-1280.png |
| Сестра без матери/отца | Первый созданный человек — sister, parent_id NULL; новая запись появляется на листе |
| Брат отдельно от сестры | Следующая запись brother, отдельная категория/лист |
| Бабушка без родителей | Сохранена maternal_grandmother без матери; общий вариант grandmother сохраняет неизвестность линии |
| Своя категория | Двоюродная сестра/Приёмная мама/Крёстный, сохранение и экранирование; изменение категории не меняет остальные факты |
| Изменение существующего листа | Короткая форма редактирования; заметка и категория сохраняются; полная прежняя история доступна по ссылке |
| Перезагрузка | Повторное открытие/перезапуск приложения сохраняют все записи и поля |
| Мобильный вид | Chromium 320/390/768/1280 px, две роли; локальная прокрутка дерева без переполнения всей страницы, без перекрытия листьев; форма помещается в экран |
| Сохранность | Сравнение всех строк 71 таблицы рабочей SQLite до/после перезапуска, целостность/внешние ключи; без новой миграции |

`browser.txt` — девять сценариев, Escape/возврат фокуса/замкнутый Tab, формы без JavaScript и сохранённая медицинская схема. `cache-browser.txt` — настоящий прогретый HTTP-кеш старого intake.css, обычная перезагрузка и отказ файлов CSS; даже без оформления сведения доступны читаемыми ссылками.

`accessibility.json` и `cache-accessibility.json` — 10 автоматических проверок axe WCAG A/AA, без нарушений. Проверка не является заявлением о полной ручной сертификации доступности. Все браузерные данные и аккаунты синтетические, в отдельной временной базе; рабочие семейные сведения и пароли в отчёты/скриншоты не включаются.

`data-check.json` содержит только количества и результат сравнения; backup находится вне Git. Прежние родственные связи, сведения о здоровье, источники, чувствительные ответы, архивы и запрет дублирования матери/отца сохранены. Качество локальных ИИ-моделей к этому изменению не относится.
