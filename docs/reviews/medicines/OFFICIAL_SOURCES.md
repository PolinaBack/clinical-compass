Не делается вывод о доступности этих сайтов с компьютера пользователя, существовании публичного API или действующей редакции какой-либо инструкции.
Ни один исходный Excel, прежний листок-вкладыш или синтетический тестовый документ не объявлен актуальным официальным источником.

Реализован контролируемый ручной импорт документа/структурированной выписки с источником, версией, РУ, точным продуктом/формой, датами, неизменяемым снимком и отдельной сверкой врачом.
Домен ГРЛС проверяется по точному разрешённому имени и HTTPS. Приложение не загружает произвольные URL и не выполняет содержимое Excel/PDF.
Техническая проверка домена не подтверждает подлинность файла: это прямо указано перед импортом и проверкой.
Для клинического использования остаются необходимыми доступная действующая инструкция, применимые российские рекомендации и независимая предметная проверка врачом.
