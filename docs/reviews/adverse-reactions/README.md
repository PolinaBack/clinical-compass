# U-ADVERSE-25: приёмка реестра и мятной библиотеки

25.10.2026, исходный коммит `49800d1`, ветка `feat/local-mvp`. [Ручная инструкция](../../ADVERSE_REACTIONS.md), [изменённые файлы](FILES.md).

## Что реализовано

Отдельная карточка «Побочные эффекты» в библиотеке и `/medicines/adverse-effects`. Используются исходные версионные записи SQLite: 468 строк/12 препаратов/15 систем. На экране медицинские и понятные названия, частоты, мятные группы по снимкам, совместные фильтры, живая выдача/счётчики, сохранение адреса, карточка/возврат и серверный поиск без JS. Неизвестная частота серая, отсутствие совпадения не является разрешением или прогнозом.

Библиотечные страницы врача — мятные: каталог/карточки/сочетания/черновики/импорт, ресурсы, каталог и формы анкет внутри `/clinical-tools`. Другие разделы и прежняя пациентская палитра не перекрашены; новый блок предпочтений имеет мятные выбранные элементы. У карточки лекарства работает активное оглавление и учёт уменьшенного движения.

В анамнез v3 добавлены добровольные поля: до трёх предпочтений и главный из них. 138 разрешённых кодов словаря сохранены, 25 остальных не предлагаются. Система/понятный и медицинский поиск, ограничение четвёртого и проверка сервера. Только отправленная версия доступна врачу; текущий приватный черновик не читается. В учебной схеме — её собственные приоритеты, звезда и точные совпадения по системе и термину. Контекст фиксируется в зашифрованной версии схемы; старая история не получает новые ответы задним числом. Никакого рейтинга, вероятности или автоматической дозы.

Присланный документ и полный текст — только в архиве разработки; в сайте нет его названия/ссылки. Справочник не выдаётся за официальную ОХЛП. Новых SQL-миграций нет: прежние неизменяемые реестры и JSON-снимки расширяются без удаления данных.

## Ограничения

34 частоты указаны в рабочем реестре, 434 требуют уточнения. ОХЛП конкретного РУ, MedDRA, экспертная/клиническая валидация, индивидуальные вероятности и реальное назначение не подтверждены и не добавлены. Выбор личного приоритета не заменяет оценку опасных проявлений. История использует зафиксированный контекст, текущий экран — последнее отправленное. Контролируемое изменение словаря требует обновления кодовой версии; импорт произвольной книги не расширяет автоматически пациентский выбор. Модели и внешние медицинские сервисы не вызывались; Windows/PyCharm здесь не запускался.
