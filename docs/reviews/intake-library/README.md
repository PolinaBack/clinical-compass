# Пол, следующий раздел и библиотека

Источник: прямое уточнение пользователя U-INTAKE-LIB-23. Приложение FastAPI/SQLite/Jinja2 сохранено; изменения ограничены анкетой и навигацией.

| Пожелание | Реализация и проверка |
|---|---|
| Пол в личных данных | Прежнее поле personal.sex выведено из дополнительных вопросов; значение хранится в версионном черновике SQLite |
| Автоматически добавить цикл | Женский пол показывает карточку в анамнезе; другим доступен ручной вход. Сохранённые ответы/вложения и старые отправки остаются доступны при смене пола. Пол не заполняет ответы о менструациях или беременности |
| Следующий раздел | Обычный POST сохраняет ответы и возвращает 303 на следующий раздел; последний ведёт к проверке, отправка врачу отдельная |
| Надёжное сохранение | Браузер: клик во время задержанного autosave и последующая правка сохраняются; проверяется 409 между двумя вкладками, сохранение без JS с клавиатуры |
| Библиотека врача | Три целиком нажимаемые карточки: препараты, рекомендованные ресурсы, анкеты; прежние URL/права/данные сохранены |
| FAQ-форум в задачах | Последняя секция /doctor/tasks; выделяется пункт Задачи; с ресурсов ссылка убрана; обсуждения не удалены |

Серверные сценарии находятся в `tests/test_intake_navigation_library.py`, браузерные — `scripts/browser_intake_library.py`. Браузерный сценарий вызывается с уже вошедшими пациентом/врачом **только на отдельной временной базе**, по образцу существующих `browser_intake.py` и `browser_e02.py`. Для axe нужен путь к локальному `axe.min.js` в `COMPASS_AXE_PATH`; без него проверки axe явно пропускаются. Рабочие записи и пароли не используются в скриншотах.

Проверяемые ширины: Chromium 320, 390, 768, 1280 px. Автоматическая доступность: WCAG A/AA, восемь проверок на 390/1280 px; ручная проверка изображений и переходов. Это не сертификация доступности и не проверка настоящего Windows/PyCharm.

Скриншоты: [Библиотека на компьютере](doctor-1280.png), [Библиотека на телефоне](doctor-390.png), [Личные данные](patient-390.png), [Вопросы о цикле](patient-cycle-390.png).

`data-check.json` содержит только результат сравнения старой SQLite и количества: 71 таблица, 551 строка, все исходные поля совпадают после полного перезапуска сервера, integrity/foreign keys OK. Резервная копия находится вне Git, новой миграции нет.

`browser.txt` — итог новой браузерной проверки, `accessibility.json` — восемь проверок axe с нулём нарушений. `browser-regression.txt` дополнительно подтверждает прежние настройки, навигацию, семейное дерево, ИМТ, создание/назначение/чтение ресурсов и экстренную помощь. Сценарии выполнялись на синтетических данных; настоящие записи встреч и локальные ИИ-модели не запускались.

`requirements-check.json` подтверждает сохранность всех 806 исходных ID/формулировок/приоритетов/зависимостей/этапов; уточнены источники, статусы и критерии трёх существующих строк. `pytest.txt` — журнал полного набора серверных тестов.
