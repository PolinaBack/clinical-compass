## Результат

Страница пациентов содержит только карточки без общего баннера и кнопок ИИ. Меню: Пациенты, Календарь, Библиотека, Форумы, Настройки. Оба форума доступны из нового раздела, старые задачи перенаправляют туда.

Календарь: дневная/недельная сетка с часами, переходы дат, выбор времени нажатием, форма без ручного ввода часов/часового пояса, реальные свободные окна и запись выбранного пациента. Занятость/пересечения/отмена/повтор проверяются сервером. Выбор пациента/встречи, создание записи прошедшего разговора и прежняя обработка медиа встроены ниже; ссылки готовых результатов также остаются в календаре. Сохраняются согласия, роли, редактирование/проверка/публикация и срок хранения.

Личный профиль показывает только доступную врачу отправленную версию анамнеза: счётчики, краткое резюме, проверки, семейную схему и сводку лекарств/реакций/болезней/пожеланий/скрининга по образцам. Возраст по умолчанию на текущую дату; существующие ограничения ИМТ и деликатных полей сохранены. Неподтверждённые/отсутствующие сведения явно отделены от медицинских фактов. Исторические препараты не названы текущими. Полная анкета/история/файлы доступны ниже и по исходным ссылкам; частный черновик не раскрывается. Анкеты/назначения/динамика объединены. Отдельные вкладки безопасности и консультаций карты убраны, исходные события/действия и пациентский кабинет сохранены.

## Ограничения

Настоящие локальные модели речи и генерации здесь не запущены; их работу/скорость/качество нужно проверить на компьютере пользователя с прежними настройками. Интерфейс не выдаёт тестовую модель за производственную: она подключается только внешним браузерным прогоном на временной синтетической базе, не через приложение.

Календарь не синхронизируется с Яндексом/другими компьютерами, не имеет drag-and-drop/растягивания или автоматического обновления сетки из другого окна. Устаревшее время всё равно проверяется при сохранении. Неизвестная длительность старых приёмов не угадывается; отображён помеченный заполнитель и сохранена форма уточнения. Создание прошедшей встречи означает запись истории для анализа разговора, а не подтверждение проведённого медицинского осмотра или подготовки. Клиническая эффективность, полнота внешних данных и Windows/PyCharm не заявляются проверенными этими техническими тестами.
