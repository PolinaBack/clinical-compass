# Общий внешний вид всех форм анамнеза

Источник U-AN-CONTROLS-24: прямой запрос пользователя 24.10.2026 и семь снимков. Изменено оформление существующих форм. Примеры новых данных/разделов с изображений не перенесены в медицинский каталог.

- Общая цветная шапка с прежними цветами/иконками, настоящим названием и номером категории.
- Белые панели вопросов; варианты в нативных radio/checkbox, шкалы 0–10, видимое выделение и фокус, единые поля даты/текста.
- Короткие кнопки Не знаю/Пропустить используют прежние статусы; прочие варианты доступны в раскрытии. Нативные элементы и обычный POST работают без JavaScript.
- Оформлены существующие связанные записи и переходы. Комментарий/Обсудить лично/Голосовая заметка/Файл раскрывают уже существующие элементы; не создают данные и не начинают запись автоматически.
- Каталог, вопросы/варианты, значения/имена полей, серверные службы/маршруты/схема базы/клинические алгоритмы не изменены.

Браузерный сценарий `scripts/browser_intake_controls.py` вызывается только на отдельной временной базе с синтетическими аккаунтами и `COMPASS_AXE_PATH`. Проверяются 0 и неизвестно/пропуск, множественный выбор, клавиатура, ветвления, перезагрузка/сохранение, без JS, ссылки на комментарий/файл, неизменяемая версия врача, общий шаблон во всех видимых разделах. Типичные формы и связанные карточки проверяются на 320/390/768/1280 px; 11 новых axe WCAG A/AA проверок.
