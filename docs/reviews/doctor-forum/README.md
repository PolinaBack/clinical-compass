# U-DOCTOR-FORUM-24: проверка форума врачей

Исходная ветка feat/local-mvp, база исходников dedb4d2. Дополнение по прямому запросу пользователя. [Инструкция](../../CLINICIAN_FORUM.md), [файлы](FILES.md).

## Реализовано

Отдельные темы «Клинический случай»/«Вопрос коллегам», ответы другого врача, фильтры/поиск с кириллицей, свои публикации и страницы. Обязательные предпросмотр и подтверждение обезличивания, ограниченная серверная проверка до выдачи предпросмотра и перед записью. Изменение/удаление своих публикаций, ревизии/повтор без дубля, немедленное скрытие темы или ответа участниками из-за возможных персональных данных; автор исправляет и публикует заново.

Роль doctor на всех новых действиях; пациент и анонимный посетитель доступа не получают. Изменение чужого текста запрещено; опубликованное обсуждение намеренно общее для врачей разных doctor_id одной установки. Нет patient_id, доступа к чужим картам, файлов, прямых ссылок, экспорта карты, публикации в FAQ или передачи ИИ.

## Практические ограничения

Текстовый фильтр не обеспечивает полную обезличенность и не гарантирует распознавание любых имён/косвенных признаков. Автор проверяет описание; любой врач может немедленно скрыть подозрительный текст. Отдельная служба модерации, проверка квалификации сотрудников, независимое рассмотрение жалоб и автоматическая юридическая оценка не реализованы. Разные локальные установки не синхронизируются; интернет-размещение не выполнялось. Удаление активного текста не очищает прежние backup или копии у читателей. Windows/PyCharm проверяется пользователем по инструкции; браузерные проверки выполнены Chromium в окружении разработки.
