# Исправление дерева при старом кеше CSS — 23.10.2026

Пользователь прислал экран со слипшимися подписями и чёрными фигурами. Новая проверка воспроизвела тот же характер дефекта со старым CSS от d7fe099, закешированным по настоящему HTTP-ответу max-age=86400. Предыдущий выпуск 7310218 проверялся в свежих контекстах и пропустил этот сценарий.

- [До исправления](before.png), [вычисленные стили](before.json), [вывод воспроизведения](reproduce.txt): position:static/display:inline у карточек и fill:black/stroke:none у SVG. Старый CSS действительно загружен один раз; следующие переходы используют HTTP-кеш. Это отдельная временная база с искусственными аккаунтами, без данных пользователя.
- [После: пациент](patient-1280.png), [телефон пациента](patient-390.png), [врач](doctor-1280.png), [телефон врача](doctor-390.png).
- [При недоступности family.css](readable-without-family-css.png): остаётся читаемый HTML-список близких, без чёрных фигур и большого пустого поля.

Изменение: URL всех подключаемых CSS/JS содержит SHA-256 от содержимого (16 символов), family.css подключён отдельно от intake.css, линии SVG явно без заливки, подписи имеют семантический список. Схема данных и логика семейных связей не менялись. Новые пакеты не требуются.

**Проверки:**

- [Полный pytest](pytest.txt): **337 passed**, 418,48 с; одно прежнее предупреждение TestClient/AnyIO.
- [Адресные тесты](pytest-targeted.txt): **15 passed**. Проверяются URL при изменении содержимого с прежними размером/mtime, реальные GET файлов, страницы обеих ролей и прежние семейные операции/права.
- [Настоящий старый кеш](browser-cache.txt): scripts/browser_family_cache.py, обычная перезагрузка, две роли, 320/390/768/1280 px; измерены позиции/размеры карточек и реальный stroke/fill SVG, нет наложения или переполнения страницы. Сначала используется реальный HTTP-кеш без Playwright-routing; только отдельные проверки отказа CSS затем используют блокировку запросов. Дерево остаётся оформленным при недоступном intake.css, при отказе family.css виден читаемый список.
- [Кабинеты](browser-cabinets.txt): создание/назначение/прочтение ресурса, поиск, дерево/медицинский вид, ИМТ 175/75 после задержки сохранения/перезагрузки, меню/помощь/настройки, четыре ширины.
- **18 текущих axe-аудитов, 0 нарушений**: 4 в accessibility.json и 14 в cabinet-accessibility.json. Проверен Linux/Chromium; это не сертификация доступности и не проверка реального Windows/PyCharm или всех браузерных движков.
- [Сравнение данных](data-check.json): все **550 строк в 69 таблицах** неизменны после перезапуска облачного приложения. integrity_check=ok, foreign_key_check без ошибок. Резервная база вне Git, ключи и клиническое содержимое не публикуются.
- Компиляция Jinja/Python, git diff --check, все **806 ID** требований сохранены.
