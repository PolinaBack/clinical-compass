## Границы

Совпадения — результаты сверки неполного справочника, не индивидуальный риск и не подтверждение безопасности. Названия не объединяются по похожести; одинаковый медицинский термин другой системы явно требует сверки. Свободный комментарий не разбирается автоматически. Используются только отправленные структурированные пожелания, а не личные черновики. Новая отправка отражается при обновлении страницы врача. Точный термин/система для прежних сохранённых совпадений не переопределён. Лечение и дозу вводит врач; новых вызовов ИИ/внешних уведомлений нет. Проверки выполнены на Linux/Chromium; Windows/PyCharm вручную не запускались.
