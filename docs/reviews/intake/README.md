# Проверка анамнеза и своих вопросов, 22.10.2026

Источники проверены по полным PDF; каталог вопросов и границы описаны в [INTAKE_FIELDS.md](../../INTAKE_FIELDS.md).

Браузер: локальный Chromium/Playwright, временная SQLite и искусственные аккаунты/данные. Существующая рабочая база не заполнялась тестовыми ответами. `scripts/browser_intake.py` вызывается из подготовленного окружения с двумя уже вошедшими ролями; настоящий MediaRecorder использует искусственный микрофон Chromium. Это проверка записи/кодирования/загрузки и FFprobe, не работы настоящего микрофона пользователя.

Сценарий прошёл: приватный черновик → автосохранение → перезагрузка → связанное заболевание/лекарство → голос → отправка → просмотр/проверка врача → свой вопрос → ответ пациента → чтение врачом. Поля достигались клавишей Tab, текст вводился клавиатурой. Проверены размеры 320/390/768/1280 px, отсутствие горизонтального переполнения и ошибок JavaScript. Выполнено **20 axe-проверок**, нарушений не найдено. Это автоматическая проверка, не сертификация доступности и не проверка всех вспомогательных технологий.

Отдельный сценарий встреч `scripts/browser_meetings.py` повторён: искусственный MP4, настоящий локальный плеер/переходы, прогресс, исправления и черновик, публикация/отзыв, запрет пациенту загружать/видеть медиа/полную расшифровку, настройки без форм врача и без повторного согласия встречи. Результат в `meetings-accessibility.json`. Ответы Whisper/Ollama в этом прогоне заменены явным `SyntheticModels` в тестовом исполнителе; реальные качество/скорость модели этим не проверялись.

`migration-check.json`: отдельная копия прежней SQLite, 54 таблицы и 536 строк до изменения; все прежние строки сохранены, кроме добавленной записи о миграции в служебном журнале, 11 новых пустых таблиц, `integrity_check=ok`, `foreign_key_check` без ошибок. После перезапуска рабочей облачной базы выполнено такое же сравнение: прежние строки сохранены, новые таблицы пусты, ключ вложений без загрузки не создавался.

Скриншоты содержат только синтетические данные. Основные зависимости установлены; Python-компиляция и синтаксис нового JS проверены. Реального ClamAV и локальных весов Whisper/Ollama в этой среде нет, поэтому их успешная работа не заявляется. Проверка антивируса честно сообщает об отсутствии; тесты сканирования используют явно подписанный тестовый ответ. Оригинал файла реально шифруется и восстанавливается из резервной БД с копией ключа.

Полный pytest и публикация коммита зафиксированы в [PROGRESS.md](../../PROGRESS.md) после завершения.
