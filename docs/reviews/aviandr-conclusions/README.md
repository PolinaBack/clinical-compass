# Приёмка U-AVIANDR-CONCLUSIONS-25

25.10.2026 · ветка `feat/local-mvp`, исходный коммит `5f7afeb`. Это техническая проверка исследовательского интерфейса на синтетических данных, не клиническая валидация.

## Реализовано

- Четыре самостоятельные функции формулируют содержательные выводы по актуальной карте. Они не выбирают заранее написанный пример по букве сценария. В каждом направлении 2–4 предложения, три основания с ID/происхождением, конкретные неизвестные сведения и 2–3 вопроса.
- Жалобы, отправленные видимые поля анамнеза, полные анкетные траектории одной версии, возраст/диагноз/факторы, текущие препараты, отметки приёма, реакции и отправленные пожелания влияют на текст. Частные черновики не публикуются, самоотчёт не превращается во врачебный факт.
- Прежний расчёт статусов/правил/пар сохранён. Отсутствие инструкции не превращается в показания, неизвестная пара — во взаимодействие, отсутствие записи — в безопасность. Нет автоматического назначения/изменения терапии.
- Ollama получает четыре индивидуальных контекста. Для каждого объяснения нужны ID фактов пациента именно этого направления. Недопустимые ID, поля статусов и ряд неподтверждённых медицинских утверждений отклоняются. Это структурные и текстовые ограничения, не доказательство смысловой правильности любого ответа модели.
- Четыре карточки открыты; «Подробнее» раскрывает записи и источники. Дневник/анкеты показаны отдельными графиками по датам, пропуски не заменяются нулями. Время открытия показывается по Москве отдельно от хеша; изменение карты/источников/версии делает прежний текст модели устаревшим.
- Последнее оформление приближено к изображению пользователя: круглые значки, мягкие акценты, компактные статусы, основания и вопросы рядом на широком экране, графики слева/вопросы и ИИ справа ниже. Существующая навигация кабинета сохранена.

Попытки дополнительного запуска вне песочницы не были выполнены. Эти попытки не считаются успешными тестами. Окончательные реальные Jinja-шаблоны сформированы по всем C/D/E без HTTP; проверены четыре вывода, уникальные ID, отсутствие вложенных форм, компиляция шаблонов и неизменность данных: [результат](static-checks.json). Проверка форматирования девяти Python-файлов прошла в одном процессе. Нужна повторная проверка окончательного оформления в обычном браузере/PyCharm.

**Настоящий отказ Ollama проверен:** отдельный worker обращался HTTP к незанятому loopback-порту; задача завершилась `provider_unavailable`, `result=null`, Python-выводы остались. [Свидетельство](real-ollama.json). Успешная генерация настоящей моделью здесь не проверена — Ollama не установлена. Успех протокола проверяется явно обозначенным тестовым транспортом, не выдаётся за генерацию модели.
