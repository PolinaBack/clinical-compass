# Приёмка U-AVIANDR-RESET-FILES-25 · 25.10.2026

Ветка `feat/local-mvp`, исходная точка `a4221ec`. Пользователь прислал `PermissionError: [WinError 5]` на `os.replace(fresh, path)` при явном запуске `scripts.setup_aviandr_scenarios --reset` в Windows/PyCharm.

## Исправление

Замена остаётся атомарной. Для временного отказа доступа/блокировки предусмотрено до пяти попыток с паузами 0,2/0,4/0,8/1,6 с. На Windows снимается read-only атрибут конкретного целевого файла; при отказе исходный режим восстанавливается на том же файле. Не изменяются ACL каталога, антивирус или права других файлов. Нет удаления занятой базы перед заменой или копирования поверх неё.

Перед каждой попыткой проверяются исходный хеш и WAL. Хеш записывается до чтения старых аккаунтов и создания копии. Если во время ожидания появились новые данные, новая база или активный WAL, повтор отменяется. При постоянном отказе CLI выходит с кодом 1 без traceback и ложного сообщения об успехе, указывает точный путь к полной копии и действия Stop/Database Disconnect. Ошибка временной очистки не перекрывает исходный отказ Windows. Для ошибок подготовки файлов также есть короткое сообщение CLI.

Открытый файл в PyCharm Database, другом SQLite-клиенте, сервере/обработчике либо отказ ОС/ACL могут продолжать блокировать замену. Скрипт не принуждает ОС закрыть чужое соединение. Инструкция описывает остановку всех процессов и Disconnect, а при необходимости запуск из обычного PowerShell после закрытия IDE.
