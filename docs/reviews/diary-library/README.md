# Проверка библиотеки карточек дневника

26.10.2026 · U-DIARY-LIBRARY-26.

## Подтверждено

`tests/test_diary_library_offline.py`: **10 passed, 1 warning, 42,85 с**, exit 0. Предупреждение — прежний deprecated alias Starlette/AnyIO при импорте тестовой инфраструктуры. [pytest-direct.txt](pytest-direct.txt).

Это прямые вызовы настоящих функций маршрутов на временной SQLite с настоящими Request/FormData, Jinja и прикладными проверками. Используется синхронное выполнение обработчиков без сетевого слушателя и event loop. Проверка не подменяет middleware HTTP, привязку параметров FastAPI, авторизацию браузерной cookie или браузерный сценарий.

Проверены:

- 43 встроенных карточки и 10 категорий, 14 шкал; предпросмотры и оба режима конструктора отрисовываются. Поиск/категория работают с выбранным пациентом и пустым выбором.
- Все 43 карточки назначены и их ответы сохранены через действующий обработчик дневника; другая карта их не видит. Врач получает основной симптом, пояснение и обсуждение.
- Диапазоны/числовой шаг, максимум три ощущения, основной только среди выбранных, атомарный отказ без записи; пустая шкала не превращается в 5.
- Повторы без дубликата, выключение/включение, прежний ответ после новой версии, собственные шаблоны отдельно по специалистам, перезапуск приложения и сохранность копии пациента.
- Проверки роли, CSRF, чужого пациента и чужого шаблона в реальных функциях маршрутов/сервисов.
- Для ощущений сохраняется последняя отправленная версия каждой схемы. Интерфейс отдельно указывает, что это не подтверждённый фактический приём и связь с препаратом не установлена.
- Прежние простые числовые/логические вопросы сохраняют 0 и «Нет».

На копии рабочей SQLite два запуска миграций сохранили все **87 прежних таблиц и 1301 строку** вне изменяемого журнала миграций. Integrity и внешние ключи в порядке. [migration.json](migration.json). Рабочая база не изменена; пароли/аккаунты не сбрасывались.

Проверены точное соответствие 43 кодов/названий документу, 806 прежних строк/ячеек требований, компиляция изменённых Python-файлов и синтаксис трёх JS-файлов. `git diff --check` прошёл. [invariants.json](invariants.json). UTF-8 задан явно для чтения каталога на Windows.
