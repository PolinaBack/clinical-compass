# Проверка упрощения выписок и фильтра формулировок

27.10.2026 · U-EXTRACT-REFINEMENTS-27 · `feat/local-mvp` поверх `10704a2`.

Удалён весь компонент «Какой документ оформить?» с дополнительным списком черновиков, его шаблон, стили и ненужное чтение всех документов внутри редактора. Создание доступно прежней одной кнопкой во вкладке «Выписки», вид — списком внутри редактора. Новые снимки источников всегда создаются с `included=False`; явный выбор врача сохраняется при сохранении/обновлении. Водяная надпись удалена из общего печатного шаблона и CSS.

Фильтр воспроизведён в настоящем Chromium: после выбора ОКР счётчик показывал 3, но видимыми оставались все 20 кнопок. Причина — более специфичный общий селектор `button:not(.text-button):not(.circle-button)` переопределял `display:none` и фон локальных кнопок. Исправлено ограниченным стилем скрытых элементов и более специфичными стилями вариантов/выбора/наведения. Алгоритм отбора и серверный поиск не менялись.
