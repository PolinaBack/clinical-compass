# Сохранение текста карточки без ограничений полей

26.10.2026. Исправлена показанная ошибка «Слишком длинное или неверное значение поля карточки». Её вызывали оставшиеся ограничения: 500 символов для метаданных, 15 000 для разделов и 2000 для ресурса при сохранении. Одно длинное поле, полученное с сайта, блокировало всю карточку.

Эти ограничения сняты на сервере и в форме сохранения. Пустые, длинные и многострочные значения принимаются без проверки медицинского формата и без обрезки пробелов/текста. Обычные поля заменены многострочными редакторами, чтобы перевод строки не исчезал при отправке. Пустое название сохраняется пустым в данных и отображается как «Лекарство без названия».

В парсере убраны обрезка разделов до 15 000, группы до 300 и извлечённого текста до 20 000 символов. В форме есть «Полученный текст / дополнительные сведения»; после сохранения его целиком можно раскрыть в блоке «Ресурс». Сведения вне узнаваемых заголовков тоже остаются в этом тексте.

Поле «Ресурс / ссылка» допускает любое текстовое значение. Неподходящий для веб-ссылки текст сохраняется и показывается обычным текстом; ссылка не превращается в исполняемый код. При фактической загрузке страницы по кнопке «Получить данные по ссылке» прежние проверки публичной HTTPS-сети и ограничения загрузки сайта сохраняются. Они не проверяют содержание сохраняемой карточки.

Обновление в PyCharm, ветка `feat/local-mvp`:

```powershell
git pull --ff-only origin feat/local-mvp
```

Перезапустите сервер и повторите сохранение. Если собираетесь обновлять уже заполненную несохранённую страницу, сначала скопируйте введённый текст или исходную ссылку, затем откройте новую форму. Для полного извлечённого текста используйте получение данных в обновлённой форме. БД и пароли не сбрасываются; новая миграция не нужна.

Ручная проверка:

1. Введите название из одного слова; оставьте МНН пустым, вставьте больше 500 символов в производителя и больше 15 000 в любой раздел. Сохраните и проверьте конец текста в карточке.
2. Получите данные со страницы с длинными разделами. Сохраните без заполнения недостающих полей и раскройте полный текст в «Ресурсе».
3. Введите произвольную подпись ресурса вместо URL: сохранение должно пройти, подпись должна остаться текстом.

Приложение сохраняет полученный текст, но не подтверждает его медицинскую точность и не гарантирует извлечение всего содержимого произвольного сайта. Проверки доступа/CSRF, принадлежности полей и повторной отправки сохранены.
