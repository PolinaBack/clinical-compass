# Кабинет, FAQ и семейная история — предыдущая компоновка

Текущие изменения кабинетов, динамики, назначений и камеры: [UPDATE_V5.md](UPDATE_V5.md).

Последнее поручение имеет приоритет над прежними планами, где были постоянные личные вопросы врачу и раздел «Мой специалист». Медицинские формы, расчёты, согласия и серверные права сохранены. Все проверки используют синтетические данные.

| Запрос | Реализация |
|---|---|
| Анонимный вопрос в самом конце FAQ до входа | Форма на главной и /faq; отдельная таблица без автора/пациента/IP; случайная ссылка для возвращения. После проверки вопрос и ответ публикуются для всех. Модерация в /doctor/faq |
| Автоматически открывать анкеты | /me открывает /patients/{id}/profile/assessments своего пациента; /me/start остаётся отдельной вводной страницей в верхнем меню |
| Плашки только в верхней панели | Личный профиль, Дневник, Динамика опросников, С чего начать; активен текущий раздел. Дублирующее меню внутри страниц удалено |
| Убрать вводные красивые фразы | У профиля, дневника и динамики короткие названия разделов. Приветственный экран сохраняет оформление главной |
| Убрать постоянные вопросы врачу | Старые POST-адреса сообщений и личных вопросов возвращают 410. UI и приглашения удалены; прежние записи в базе сохранены |
| Дневник и отдельная заметка | Запись/история и диаграмма самочувствия, заметки к приёму; заметка доступна назначенному специалисту, без обязательных баллов самочувствия |
| Отдельная динамика, подписать оси | В динамике PHQ-9/GAD-7, в дневнике самочувствие; у всех календарная ось X, подпись величины/шкалы на Y, даты и значения; неполные формы разрывают линию |
| Профиль загружает блоки раздельно | /profile/about, /profile/assessments, /profile/family, /profile/video; сервер возвращает только выбранный экран |
| Отчёты из профиля в динамику | Создание черновика, публикация и просмотр в /results#reports. Полезные материалы и блок событий/решений из профиля убраны |
| Убрать «Мой специалист» | Пункта и страницы больше нет; прежний /contact переадресует на видеосвязь в профиле |
| Запись и видеосвязь в профиле | Пациент оставляет заявку с датой/интервалом/поясом; специалист подтверждает фактическое время и HTTPS-ссылку. Запись не выдается за подтверждённую до его действия |
| Генограмма по приложенным изображениям | Сиреневое дерево с двумя ветвями, карточками-листьями, статусами и отметкой обсуждения; переключение дерево/список. Отдельные страницы близкого: описание, что известно, пояснения |
| Источники семейных сведений | Видимые вопросы и варианты ответов воспроизведены по фотографиям. Произвольное название/описание, редактируемые примерный возраст, источник и неуверенность; отдельная сводка. «Не знаю», отказ и отложенное заполнение не заменяются отсутствием заболевания |
| Сохранность старых данных | Аддитивная миграция; именованные родители попадают в свои слоты без дублирования. Старые аккаунты, анкеты, сообщения и вопросы сохраняются; тип прежних семейных записей остаётся нейтральным (unspecified), без предположения о диагнозе |

Форум не является пациентской картой или экстренным каналом. Вопросы не публикуются автоматически до ответа; автору не нужно сообщать имя или контакт. Технические журналы вне приложения не исследованы, абсолютная анонимность не обещается. Текст, который пользователь сам опубликует, может содержать узнаваемые сведения, поэтому форма заранее обозначает публичный формат.

Реальный видеосервис должен предоставить владелец проекта/клиника. Учебная адаптация C-SSRS, отсутствие точных критериев MADRS/HDRS и остальные клинические границы описаны в CLINICAL_GAPS.md и CSSRS_ADAPTATION.md. Эти изменения не включают новую интерпретацию медицинских шкал.
