# Сброс опросников и первичного анамнеза демо-пациентов

Разрешение пользователя: очистить прежние заполнения **и во вкладке «Анкеты», и в первичном анамнезе «Обо мне»**. Команда работает только с исходными профилями **1 — «Демо-пациент А»**, **2 — «Демо-пациент Б»**. Проверяются названия и известные логины демо-аккаунтов. Произвольные другие пациенты и переименованные профили не сбрасываются.

## Запуск на вашем компьютере

1. Остановите сервер и ИИ-обработчики через **Ctrl+C** в их терминалах.
2. В Terminal PyCharm из корня проекта обновите ветку:

   ```powershell
   git pull --ff-only origin feat/local-mvp
   ```

3. Посмотрите список затрагиваемых записей, пока без изменений:

   ```powershell
   .\.venv\Scripts\python.exe -m scripts.reset_demo_forms
   ```

4. Для сброса обоих разделов у двух демо-профилей:

   ```powershell
   .\.venv\Scripts\python.exe -m scripts.reset_demo_forms --apply
   ```

5. Сохраните путь резервной копии из вывода команды, затем снова запустите приложение и нужный ИИ-обработчик. Откройте формы заново — старые вкладки с незавершёнными правками лучше закрыть.

Если задан нестандартный `COMPASS_DB`, команда использует его. Можно явно указать `--database "путь\к\compass.db"`. Новой базы команда не создаёт и миграции не применяет: для старой неподготовленной схемы сначала запустите актуальное приложение. Для отдельной копии можно задать `--backup "путь\к\новой-копии.db"`; существующий файл не перезаписывается. `--patients 1` ограничивает операцию первым демо-профилем; по умолчанию выбраны оба.

## Что сбрасывается

- Числовые/текстовые ответы, комментарии и история опросников PHQ/GAD/HCL/безопасности, связанные старые тестовые события, сохранённые запросы повторной отправки и медиа именно этих опросников. Назначенные формы и сессии остаются, их статус возвращается к черновику, ревизия увеличивается для защиты от старой вкладки. Прежние самостоятельные самоотчёты `screenings` тоже очищаются.
- Черновики, отправленные версии, записи/связи/вложения и история первичного анамнеза, врачебные уточнения отправленных версий и прежние свободные поля «Обо мне».
- Старые ИИ-снимки и результаты выбранных демо-карт, содержащие копии очищаемых ответов.

Аккаунты, имена профилей, пароли, согласия, настройки, дневник и его файлы, сообщения, отдельное семейное дерево, консультации и записи встреч сохраняются. Другие пациенты остаются без изменений. Файлы удаляются только как записи соответствующих таблиц БД; произвольные пути из полей базы не используются для удаления файлов на диске.

## Защита данных

Без `--apply` выводится только предварительный просмотр. Перед действительным сбросом создаётся **полная согласованная SQLite-копия** в `data/backups/` либо по указанному пути. При наличии зашифрованных вложений/ИИ-снимков сохраняется также `.db.key`; ключ проверяется расшифровкой удаляемых данных в копии. Само содержимое в журнал не выводится. Для восстановления нужны база и её ключ. Полное восстановление возвращает **всю базу** к моменту этой копии, а не только отдельные формы.

Сброс выполняется одной транзакцией. Если после копирования изменились затрагиваемые данные, обнаружены чужая связь, свежая работающая ИИ-задача, неверный/утраченный ключ или иная ошибка, изменения не применяются. При работающем ИИ остановите обработчик; после последней связи ему отведено до 90 секунд, прежде чем сброс станет доступен. При повторном запуске уже пустые формы не меняются, лишняя копия не создаётся.

## Что выполнено здесь

В доступной рабочей копии оба демо-профиля уже имеют пустые опросники и первичный анамнез. Команда с `--apply` проверена: изменений нет. Ваша Windows-база отдельно не изменялась; `git pull` сам её не очищает. Для неё нужен приведённый выше запуск команды.
