# Свободный ответ локальной Ollama

26.10.2026 · U-AI-FREE-TEXT-26, уточнён U-AI-PRESENTATION-26. Оба запуска вкладки «Анализ ИИ» теперь всегда запрашивают свободный текст без проверки содержания. Переключатель формата убран. [Текущий экран и установка](AI_PRESENTATION.md).

## Обновить в PyCharm

```powershell
git switch feat/local-mvp
git pull --ff-only origin feat/local-mvp
```

Перезапустите приложение **и обработчик ИИ**, чтобы оба использовали новый код. Ollama должна работать с установленной локальной моделью. В отдельных терминалах корня проекта:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

```powershell
.\.venv\Scripts\python.exe -m scripts.patient_ai_worker
```

БД не очищается, миграций нет. Обновите страницу Ctrl+F5. Старые ошибки и исторические результаты не переписываются: создайте **новый** запуск. Старый отклонённый текст, который не был сохранён, восстановить нельзя.

## Работа врача

1. Откройте **Пациенты → выбранная карта → Анализ ИИ**. Для подробной синтетической карты можно выбрать «Абсолют» у специалиста 1.
2. **«Проанализировать эту карту»** запрашивает общую сводку; **«Объяснить этот расчёт с помощью ИИ»** — текст по четырём направлениям Авиандра.
3. После окончания результат появляется автоматически с пометкой **«Непроверенный ответ модели»**. При сбое подгрузки используйте соответствующую кнопку обновления результата.
4. После изменения карты запустите новый анализ для актуального текста. Прежний полученный ответ остаётся доступен с привязкой к своему снимку.

В свободном режиме Ollama получает обычный текстовый запрос без обязательной JSON-схемы. Полученный текст сохраняется дословно: не требуется заданное число вопросов, существующие ID оснований или прохождение прежних текстовых фильтров. Даже короткий текст, отказ модели, невалидный JSON или медицинские фразы, которые ранее отклонялись фильтром, показываются врачу. Это **не подтверждение их правильности**. Инструкции модели по-прежнему просят отделять факты от гипотез, не придумывать сведения и не назначать персональную терапию; выполнение этих инструкций в свободном ответе автоматически не проверяется.

Обрезанный непустой ответ показывается с отметкой **«Получена только часть ответа»**. Если текст пуст, нет соединения, модель не установлена, запрос отклонён или превышен технический предел HTTP-ответа, остаётся конкретная ошибка: текста для показа нет. При обрыве транспорта до получения корректного HTTP-пакета частичный поток не восстанавливается. Приложение использует прежний `stream=False`.

Ответ хранится зашифрованным и доступен прежним разрешённым ролям. HTML и ссылки отображаются обычным текстом: модель не может выполнить скрипт или выдать свою ссылку за проверенный источник. Текст не записывается в назначения, медицинские факты, правила или статусы четырёх карточек. Доступ ведущего врача, согласие, CSRF, локальный адрес и проверка отсутствия облачной модели сохраняются. Ошибки доступа останавливают сохранение результата; изменение карты во время генерации помечает текст как относящийся к прежнему снимку, сохраняя полученный ответ.

Старые очереди и API-клиенты без указания формата продолжают запрашивать структурированный режим, но при неудаче проверки полученный непустой ответ сохраняется как непроверенный текст. Новая форма отправляет явный `response_mode=free`. Повтор того же запроса идемпотентен. Отдельная синтетическая лаборатория сохраняет строгие проверки.

У кнопок обновления расчёта/объяснения есть отдельный публичный параметр `refresh`, который меняется при отображении страницы. Он заставляет браузер выполнить новый GET даже при совпадении адреса и якоря, не влияет на данные или хеш снимка и не запускает модель.

## Проверить

- Запустите оба вида анализа в свободном режиме; проверьте пометку и собственный текст установленной модели.
- Убедитесь, что нет переключателя формата и показанный непустой ответ не отклоняется из-за числа вопросов, ссылок или медицинских фраз.
- Добавьте новое сведение карты: расчётные карточки обновятся, прежний текст не станет автоматически актуальным.
- Остановите Ollama и повторите запуск: должна появиться ошибка соединения без заготовленного ответа.

```powershell
.\.venv\Scripts\python.exe -m pytest -q tests/test_ai_free_text.py tests/test_patient_ai.py tests/test_aviandr_research.py
```

Успешная генерация именно вашей локальной моделью требует ручной проверки. Технические тесты используют явно отмеченный тестовый HTTP-транспорт; клиническая достоверность свободного текста не подтверждена.
