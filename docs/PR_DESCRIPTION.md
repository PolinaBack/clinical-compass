Локальный MVP «Клинического компаса» вместо пустого репозитория: пациент сохраняет дневник и самоотчёт, сообщает о рисках и задаёт вопрос; ведущий демоврач видит данные, отвечает, подтверждает просмотр событий и сохраняет собственное решение с основанием. Добавлены динамика, демонстрационные уведомления, визуальные категории маршрутизации, упрощённая генограмма и необязательный голосовой ввод.

FastAPI + SQLite + Jinja2, без сборки фронтенда и внешних сервисов для основного сценария. Есть инструкции PowerShell/PyCharm, синтетическое наполнение пустой базы и согласованное резервное копирование SQLite. Базы, секреты и окружение исключены из Git.

Проверки: 28 pytest-тестов прошли на Linux/Python 3.12; браузерный smoke в Chromium прошёл сквозной путь и проверку мобильной ширины; ошибок JavaScript нет. Проверены pip check, компиляция Python, синтаксис JavaScript и git diff --check. Windows CI добавлен, но его выполнение ещё не подтверждено. Микрофон фактически не проверен.

Не завершены обязательные клинические условия кейса: валидированный русский скрининг, автоматический клинический триаж, проверенные сведения о терапии и сценарии назначения «Авиандра». Первоисточники запрошены; доступ к официальным каталогам из текущей среды отклонён proxy 403. Демоанкета и срочные демосигналы не объявляются заменой этих функций. Подробная матрица: docs/REQUIREMENTS.md и docs/CLINICAL_GAPS.md. Открытые демороли предназначены только для localhost и синтетических данных; готовность к реальной клинической эксплуатации не заявляется.

Дополнительно: справка для демоврача по предоставленному листку-вкладышу «Авиандра» (показания, ограничения, взаимодействия, режим приёма, нежелательные реакции). Сохранён оригинальный PDF с SHA-256, каждая группа сведений ссылается на страницы. Актуальность редакции по ГРЛС не подтверждена; справка не порождает назначений. Доступ пациента к справке/PDF закрыт. Валидированные шкалы отложены по решению пользователя.
