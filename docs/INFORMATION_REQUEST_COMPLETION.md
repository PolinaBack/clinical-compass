# Ответ на запрос врача после сохранения раздела

Врач запрашивает лекарства, аллергии, заболевания или пожелания из сводки личного профиля пациента. Пациент открывает нужный раздел, заполняет ответ и нажимает **«Сохранить раздел»** либо **«Сохранить карточку»**. Отдельная отправка всей первичной анкеты больше не нужна.

Передаются только запрошенные сведения. Например, сохранение лекарства отвечает на запрос о лекарствах; неопубликованные аллергии, личные данные и другие разделы остаются черновиками. Уже отправленные ранее сведения сохраняются в новом снимке. Ответ «Нет» также считается ответом; пустой раздел запрос не закрывает. Состояния «Не знаю», «Обсудить лично» и аналогичные передаются без подмены медицинским отрицанием.

Автосохранение при вводе остаётся личным, включая карточки лекарств и реакций. Отправку выполняет явная кнопка сохранения. Пациент видит подтверждение передачи; запрос и отметка «По просьбе врача» исчезают. Если запрошено несколько разных тем, исчезают только получившие ответ.

У врача кнопка запроса заменяется зелёной отметкой **«Ответ получен»** и ссылкой **«Открыть сведения»**. Это подтверждение получения ответа, а не медицинской достоверности. Открытые вкладки проверяют статус раз в 10 секунд и при возвращении в окно; без JavaScript результат виден после обновления страницы. Прочее содержимое уже открытой карты можно перечитать по ссылке на сведения.

Запрос «Пожелания и незавершённые опросники» по-прежнему учитывает опросники, которые врач включил в запрос: сохранённые пожелания передаются сразу, а сам запрос остаётся до завершения этих опросников.

Каждая новая передача создаёт неизменяемый отправленный снимок, без изменения прежних версий и чужих разделов. Повторное подтверждение неизменившихся сведений использует уже отправленный снимок. Позднейшая обычная отправка всей анкеты сохраняет остальные изменения отдельно.

Обновление: получить изменения ветки `feat/local-mvp`, перезапустить веб-сервер и обновить вкладки браузера. Дополнительные скрипты, миграция, очистка БД или перезапуск Ollama для этой функции не нужны. [Проверки](reviews/information-request-completion/README.md).
