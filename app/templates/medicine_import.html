Официальная инструкция или выписка из неё

Автоматическая сверка с ГРЛС не подключена: доступ из облачной среды заблокирован (403). Проверяющий врач должен самостоятельно открыть действующую запись ГРЛС и сверить точный продукт, форму, РУ, редакцию и каждый переносимый фрагмент. Ссылка сама по себе не доказывает подлинность файла.

Загрузите PDF инструкции и заполните только подтверждённые поля либо подготовьте XLSX по шаблону официальной выписки. Это ручная выписка; универсальный API ГРЛС не предполагается. Для новой редакции загрузите новый документ. Старую можно отозвать, сохранив историю.

Срок повторной сверки — не больше 366 дней с даты сверки. Истечение срока исключит сведения из проверенных; это не срок действия РУ.
